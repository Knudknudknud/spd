\begin{abstract}
Parameter decomposition methods aim to express a trained network as a sum of simpler components that
are faithful to the model's weights, with each component corresponding to a distinct mechanism.
Stochastic Parameter Decomposition (SPD) does so by constraining each component to its simplest,
rank-one form and learning an importance assignment that decides which components are responsible for
a given input. Since the components are constrained to be rank-one, higher dimensional
features can not be captured during training and must instead be reassembled by clustering
multiple lower rank components together post training.

To explore whether this grouping can instead be done during training, the SPD architecture is adapted
to use rank-$k$ subcomponents together with a relational importance assignment that computes importance across subcomponents rather than independently.

This reformulation while producing sparser importance assignments, appears to be a poor
guide to the decomposition underneath. In this setting a one-hot importance assignment does not imply complete ownership,
since the components it marks as unimportant still carry relevant magnitude that contribute to the
output. It is concluded that, under this reformulation, the importance values can not be taken
as literal measures of feature ownership, and that other approaches should be considered if higher-dimensional features are to
be captured during training.

\section{Introduction (mangler rettelser, ellers done)}

Mechanistic interpretability seeks to reverse-engineer neural networks into a set of
human interpretable mechanisms. Different branches of the field pursue this goal with different
focal points, either by disentangling directions in activation space, discovering computational subgraphs, or
decomposing the network's parameters directly.

However, both the atomic structure for decomposition
 and the decomposition itself remain open problems.
\autocite{sharkey2025openproblemsmechanisticinterpretability}
Whether a decomposition recovers the computational primitives
of a neural network depends on what the ground truth decomposition
is taken to be. With models consisting of independent features,
the decomposition is unambiguous, with one atom per feature.
If the features are dependent or co-occur, the decomposition becomes underdetermined.
Decompositions that split features across multiple atoms, risk losing the structural information, that gives each feature its meaning,
while decompositions that group multiple features into a single atom, risk losing granularity by collapsing distinct features into a single unit.

For example, a network computing the volume of a cube can be
decomposed into components corresponding to individual side
lengths, or into a single component computing the volume directly.
The former corresponds to a feature-level decomposition,
with one atom per input direction, exposing internal
structure but leaving grouping implicit, only recoverable
through co-activation patterns. The latter corresponds
to a structural-level decomposition, with one atom per
computation, exposing the grouping directly but collapsing per side-length information.

% Recently, 
% a formal definition of irreducibility was introduced to disambiguate cases such
% as the cube example.
% \autocite{engels2025languagemodelfeaturesonedimensionally}
% Features are irreducible, and thus constitute units of decomposition,
% if their joint distribution can not be decomposed into independent
% factors or into a mixture of mutually exclusive events.

Beyond what the atoms should be, the decomposition procedure itself remains open.
Recent work focuses on decomposing parameters, as opposed to the activations.
These methods aim to recover components that are faithful to the original weights, sparse per input, and individually simple. 
One such approach, Stochastic Parameter Decomposition (SPD) \autocite{stochasticparameterdecomposition}, factorizes networks into rank-one components with a learned per component importance
function.

This work examines SPD in settings with multi-dimensional
features that can not be captured by a single rank-one component,
to see whether they can be recovered during training rather than
through post-hoc clustering.
To
explore this, the subcomponents are extended to rank k and a joint, relational importance function
is introduced, computed across subcomponents rather than independently. 
Lastly, a new toy model, the Toy
Model of Geometry, is introduced to evaluate both SPD and the modification in a higher-dimensional setting.

Across the toy models studied, the relational importance function, implemented as a transformer
block with softmax over subcomponents, recovers sparser, near one-hot causal importance
assignments. These sparse
assignments are misleading, however, since they do not correspond to an equally sparse parameter
decomposition, and the underlying representation stays distributed across multiple subcomponents even
when the importance values suggest a monosemantic split.

Secondly, in the Toy Model of Superposition it is found
that constraining a subcomponent to rank one does not restrict
it to a single input. When two inputs are sampled together,
the model collapses them onto a shared direction in its hidden space,
and a single rank-one subcomponent then captures both,
just as it would a single independent input. Rank-one therefore
does not appear to indicate the simplest decomposition of the inputs,
since what a rank-one subcomponent captures depends on the model
transformation, and specifically on how it has collapsed those
inputs in its hidden space, rather than on the input distribution
in isolation.

Finally, the Toy Model of Geometry shows that the rank-$k$ extension does not translate to SPD
without further modification, as increasing the rank produces the opposite of the intended effect.
Rather than allowing a single subcomponent to absorb an entire feature, the added capacity is used
to share several features across fewer subcomponents, entangling computations that should remain
separate.


\section{Related work (Done to rettelser)}
\subsection{The linear representation hypothesis}
A widespread view in mechanistic interpretability is the linear
representation hypothesis: high-level concepts are encoded as directions
in a network's representation space \autocite{park2024linearrepresentationhypothesisgeometry}.
Together with the superposition hypothesis \autocite{elhage2022toymodelssuperposition},
it forms a central tenet of interpretability, that each feature corresponds
to a single direction, and a hidden state is a sparse linear
combination of feature directions.

Recent work questions how strictly this view should be taken,
distinguishing between a weak form of the hypothesis,
that \textit{some} features are linear, from a stronger form that
\textit{all} features are linear \autocite{mendel2024sae,smith2024strong}. 
Empirically multiple counterexamples to
the stronger form have been proposed, including recurrent
networks that encode token position by magnitude
\autocite{csordás2024recurrentneuralnetworkslearn}, transformers
representing cyclical concepts such as days of the week
\autocite{engels2025languagemodelfeaturesonedimensionally} or modular
arithmetic \autocite{nanda2023progressmeasuresgrokkingmechanistic} in
irreducible low-dimensional subspaces.
\subsection{Activation-space decomposition}
Decomposing a network's activations  focuses on disentangling layer activations into interpretable features.
Here, sparse autoencoders (SAE) are one of the most widely researched methods \autocite{sparseautoencodershighlyinterpretable, bricken2023monosemanticity},
that learn an overcomplete dictionary that expresses each hidden state as a sparse combination of one-dimensional features.
However, these features are not necessarily aligned with the network's computation, due to feature absorption, inconsistencies across dictionary sizes, and a failure to capture feature geometry.
 \autocite{absorptionstudyingfeaturesplitting, sparseautoencoderscanonicalunits,mendel2024sae}.

Circuit discovery extends feature analysis to identify
how a computation is processed by the network's structure,
by identifying  minimal subgraphs required to perform a given task,
without loss of precision. \autocite{olah2020zoomin,marks2025sparsefeaturecircuitsdiscovering}.
However, these methods generally do not account for the
polysemantic and densely connected structure of neural networks,
where the functional behaviour can be attributed to multiple distinct but functionally equivalent subgraphs \autocite{méloux2025everythingeverywhereoncemechanistic}.

\subsection{Parameter-space decomposition}

Recently a newer line of work aims to decompose the network's parameters directly, instead of the activations.
Transcoders \autocite{dunefsky2024transcodersinterpretablellmfeature} represent an intermediate step that learns a sparse approximation of an MLP layer. Parameter decomposition methods go further, factorising the network's weights directly, with the goal of recovering the network's computational primitives.

Most directly relevant to this work is the description-length-driven
line of Attribution-based Parameter Decomposition
\autocite{AttributionBasedParameterDecomposition} and
Stochastic Parameter Decomposition (SPD)
\autocite{stochasticparameterdecomposition}, which has
recently been explored in small transformer models
\autocite{christensen2025decompositionsmalltransformermodels}
and cross-layer clustering \autocite{seshadri2026crosslayer}.
While APD decomposes a network into multidimensional
components,
the method is sensitive to hyperparameters, and does not scale beyond toy settings due
to computational complexity. SPD addresses this
by decomposing each weight matrix into rank-one
subcomponents and learning a per-input importance
function over them, at the cost of requiring post-hoc
clustering to recover higher-rank mechanisms;
both methods are detailed in
Section~\ref{sec:spd_background}.

In concurrent work, adVersarial Parameter Decomposition (VPD)
\autocite{bushnaq2026interpreting_new_spd} extends this line of
research by replacing SPD's stochastic masking procedure with an
adversarial objective that searches for subcomponent ablations capable
of invalidating the learned importance assignments. The method enforces
that, for any input, every subset of subcomponents containing those
identified as causally important must still reconstruct the network's
output. VPD also scales parameter decomposition to a small
language model.

\section{Method (done until korrektur)}

\subsection{Background on SPD}
\label{sec:spd_background}
Attribution-based Parameter Decomposition (APD) \autocite{AttributionBasedParameterDecomposition}
and Stochastic Parameter Decomposition (SPD) \autocite{stochasticparameterdecomposition} both aim to decompose
a network's parameters into a set of components that are faithful
to the original weights, minimal in the number required per input,
and individually as simple as possible.

To formalise this, consider a neural network $f(x, W)$ with weight matrices $W = \{W^1, \dots, W^L\}$.
A set of parameter components are said to comprise the network's mechanisms if they satisfy the following properties:
\renewcommand\labelitemi{\tiny$\bullet$}
\begin{itemize}
    \setlength\itemsep{0em}
    \item \textbf{Faithfulness}: The parameter components should sum to the 
          parameters of the original network.
    \item \textbf{Minimality}: As few parameter components as possible should 
          be required to replicate the network's output on any given input.
    \item \textbf{Simplicity}: Each component should span as few weight 
          matrices and as few ranks as possible.
\end{itemize}

APD \autocite{AttributionBasedParameterDecomposition} approaches this by decomposing
the network into a set of parameter components without constraining
their rank, using a gradient-based attribution that selects the top-$k$ components most
responsible for any given input. While effective on small models,
APD scales poorly: its memory cost grows with the number of components,
as each component has the same dimensionality as the original network,
and its top-$k$ attribution is sensitive to hyperparameter choice.

SPD \autocite{stochasticparameterdecomposition} addresses these limitations by enforcing a rank-one structure on each component, and replacing top-$k$ attribution with a learned causal importance function. Formally, each weight matrix $W^l$ is decomposed into a sum of $C$ rank-one subcomponents:
\begin{equation}
W^{l}_{i,j} \approx \sum_{c=1}^{C} U^{l}_{i,c} V^{l}_{c,j}, 
\quad \text{where} \quad U^l \in \mathbb{R}^{d_{\text{out}} \times C}, \, V^l \in \mathbb{R}^{C \times d_{\text{in}}}
\end{equation}
where C is a hyperparameter, for the number of components for each layer, $l$ indexes the layer and $i,j$ are the hidden indices.
The subcomponent count, C, may be chosen to be larger than both $d_{in}$ and $d_{out}$, enabling the method to learn features in superposition \autocite{stochasticparameterdecomposition}.

To enforce the properties above, three losses are introduced, which are optimised jointly.
Faithfulness is enforced thorugh a mean squared error loss between the original network's weights and the sum of subcomponents:

\begin{equation}
    \mathcal{L}_{\text{faithfulness}} = \frac{1}{N} \sum_{l=1}^{L}\sum_{i,j} \left( W_{i,j}^{l} - \sum_{c=1}^{C} U^{l}_{i,c}V^{l}_{c,j} \right)^{2}  
\end{equation}
where $N$ is the total parameter count in the target model.

Optimization for simplicity and minimality is achieved through a
stochastic masking procedure. Intuitively, if a subcomponent is not
necessary for reconstruction, it can be sampled to zero without loss
of faithfulness. A causal importance function
$\Gamma: \mathcal{X} \to [0,1]^{C \times L}$ is trained to learn the
lower bound of the ablation. In SPD, $\Gamma$ is a set
of independent MLPs $\gamma^l_c$ that each take a layer's activation
and output a scalar importance for the corresponding subcomponent:
\begin{equation}
g^{l}_{c}(x) = \Gamma^l_c(x) = \sigma_{H}(\gamma^{l}_{c}(h^{l}_{c}(x))), \qquad h^{l}_{c}(x) = \vec{V}_{c}^{l\top} \vec{a}^l(x)
\end{equation}
here $\sigma_{H}$ is a hard sigmoid and $\vec{a}^l(x)$ is the
activation vector of layer $l$. $g_c^{l}(x)$ serves as the lower bound for how much a subcomponent can be masked. With $r^l_{c} \sim \mathcal{U}(0, 1)$ sampled per subcomponent, the masked weight matrix $W^{'l}$ is given by:
\begin{equation}
\begin{aligned}
    m_{c}^l(x, r) &= g^{l}_{c}(x) + \bigl(1 - g^{l}_{c}(x)\bigr)\, r^l_{c}, \\
    W'^{l}_{i,j}(x, r)  &= \sum_{c=1}^{C} \vec{U}_{i,c}^{l}\, m_{c}^l(x, r)\, \vec{V}_{c,j}^{l},
\end{aligned}
\end{equation}
These masked matrices are trained to reconstruct the original network's output.
\begin{equation}
    f\!\left(x \,\big|\, \{W'^{l}(x, r)\}_{l=1}^{L}\right)
    \approx
    f\!\left(x \,\big|\, \{W^{l}\}_{l=1}^{L}\right).
\end{equation}
This is done through both a layer-wise and a global reconstruction loss. The layer-wise version is necessary to provide a stronger training signal as randomly masking all components at the same time can be too noisy to learn from.

\begin{equation}
\begin{aligned}
    \mathcal{L}_{\text{stochastic-recon}}
      &= \frac{1}{S} \sum_{s=1}^{S}
         D\!\left(f\bigl(x \mid W'(x, r^{s})\bigr),\; f(x \mid W)\right), \\
    \mathcal{L}_{\text{stochastic-recon-layer}}
      &= \frac{1}{LS} \sum_{l=1}^{L} \sum_{s=1}^{S}
         D\!\left(f\bigl(x \mid W^{1}, \dots, W'^{\,l}(x, r^{(s)}), \dots, W^{L}\bigr),\;
                  f(x \mid W)\right).
\end{aligned}
\end{equation}
where $D$ is a task-specific divergence measure, such as MSE or KL divergence.

Lastly, to enforce minimality, the importance function
is trained to activate only the subcomponents
required to reproduce the target model's output,
leaving the rest inactive. The loss balances
reconstruction accuracy against the number of
active subcomponents, creating a tradeoff between
faithfulness and minimality.
\begin{equation}
    \mathcal{L}_{\text{minimality}}
      = \sum_{l=1}^{L} \sum_{c=1}^{C} \bigl(g^{l}_{c}(x)\bigr)^{p},
      \qquad p > 0.
\end{equation}
\label{spd_minimality}

The full SPD objective is a weighted sum of these terms:
\begin{equation}
    \mathcal{L}_{\text{SPD}}
      = \mathcal{L}_{\text{faithfulness}}
      + \beta_{1}\, \mathcal{L}_{\text{stochastic-recon}}
      + \beta_{2}\, \mathcal{L}_{\text{stochastic-recon-layer}}
      + \beta_{3}\, \mathcal{L}_{\text{minimality}}.
\end{equation}


\subsection{Irreducibility and the natural unit of decomposition}
\label{sec:irreducibility}
A growing body of work has identified irreducible
multi-dimensional features in trained models,
in which concepts are encoded in higher-dimensional
subspaces that can not be decomposed into independent
one-dimensional features
\autocite{engels2025languagemodelfeaturesonedimensionally}.
This has prompted a redefinition of the superposition
hypothesis, which originally took features to be sparse
and one-dimensional, to allow features that are
irreducible and may span more than a single direction.

\textbf{Definition: Multi-dimensional superposition hypothesis}\\
Every hidden
state $x_{i,l}(t)$ can be written as a sum of feature contributions
\begin{equation}
    x_{i,l}(t) = \sum_j V_j \, f_j(t),
\end{equation}
where each $f_j(t) \in \mathbb{R}^{d_{f_j}}$ is an irreducible feature with
internal dimensionality $d_{f_j} \geq 1$, each $V_j \in \mathbb{R}^{d \times d_{f_j}}$,
and $\| V_k^\top V_r \| < \delta$ for $k \neq r$.

Here an irreducibile feature is one that can not be decomposed into two independent or mutually exclusive features, as defined below.
The original mixture case is self-contradicting, so it is restated as in \autocite{busch2025}.

\textbf{Definition: Reducibility} \\
A feature $f: \mathcal{X} \to \mathbb{R}^{d}$,
with $\mathcal{X}$ a subset of the input space, is reducible into features
$G:\mathcal{X}\to\mathbb{R}^{k}$ and $H:\mathcal{X}\to\mathbb{R}^{d-k}$, with
$k, d-k > 0$, if there exists an affine transformation
\begin{equation}
    Rf + v = \binom{G}{H}
\end{equation}
for some orthonormal $R \in \mathbb{R}^{d \times d}$ and vector
$v \in \mathbb{R}^{d}$, where one of the following holds:
\begin{itemize}
    \setlength\itemsep{0em}
    \item \textit{Independent}: $P(G \in A_{G}, H \in A_{H}) = P(G \in A_{G})\,P(H \in A_{H})$
    \item \textit{Mixture of mutually exclusive features}: $P(G \neq 0, H \neq 0) = 0$
\end{itemize}
A feature that satisfies neither is irreducible.

Reducibility and the multi-dimensional superposition hypothesis
jointly define the internal structure of a feature, and
when it is in its smallest form. They do not, however,
define what the features are in the first place, nor how they
should be extracted from the network's parameters. SPD addresses
this, but in its original form recovers only rank-one
subcomponents and can not express the multi-dimensional features
these definitions require.
This gap is what motivates adapting SPD to higher rank.
Rather than clustering rank-one subcomponents post-hoc,
the rank-one subcomponents are replaced with rank-k
subcomponents, so that multi-dimensional features can be represented
directly during training. This restructured formulation
is introduced in Section~\ref{sec:rank-k-attention}.

\subsection{Rank-$k$ subcomponents and relational importance}
\label{sec:rank-k-attention}
In the original SPD paper, the subcomponents are constructed as rank-one matrices,
through an outer product of two vectors. As motivated in
Section~\ref{sec:irreducibility}, a rank-one subcomponent can not
represent an irreducible multi-dimensional feature, forcing it to either
 be split across multiple subcomponents or approximated by a single one at
the cost of reconstruction. To allow such features to be captured during training,
the pairs of vectors are replaced with pairs of matrices.
\begin{equation}
W^{l}_{i,j} \approx \sum_{c=1}^{C} \sum_{r=1}^{k} U^{l}_{c,i,r} V^{l}_{c,r,j},
\quad \text{where} \quad U^l \in \mathbb{R}^{C \times d_{\text{out}} \times k}, \, V^l \in \mathbb{R}^{C \times k \times  d_{\text{in}}}
\end{equation}
Each subcomponent $U^l_c {V^l_c} \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$
has rank at most $k$, recovering the original SPD definition when $k=1$.
As in the multi-dimensional superposition hypothesis, $k$ is an upper bound on
each subcomponent's representational capacity; the effective rank may be lower.

In SPD, each subcomponent's importance is computed independently through an MLP followed by a sigmoid nonlinearity,
allowing multiple subcomponents to be active for a given input and thus distribute a
feature across them, even when it is irreducible. Likewise, the minimality loss does not translate to the rank-k setting, where each subcomponent can represent multiple feature directions:
it imposes little penalty for distributing a feature across multiple subcomponents,
nor for a single subcomponent to encode parts of multiple features. (Section \ref{spd_minimality})

To address this, the causal importance function is redefined to maximize the conditional probability, that a given subcomponent $W_{c}^{l}$, is responsible for a given feature, conditioned on the activations of all other subcomponents in the same layer.
\begin{equation}
    g^l_{c}(x) = p\!\left(W^l_c \mid \{h^l_{c'}(x)\}^{C}_{c'=1}\right), \quad h^l_c(x) = {V^l_c}^{\top} \vec{a}^l(x) \in \mathbb{R}^k
\end{equation}
here $\vec{a}^l(x)$ is the activation vector of layer $l$ and C is the set of subcomponents in layer $l$, $g^{l}_{c}(x)$ the causal importance value and $h_{c}^l$ the input to the causal importance function.

The conditional importance is computed using a standard transformer block following the architecture of \autocite{vaswani2023attentionneed}. For each layer l,
the read activations \(h_c^l(x) \in \mathbb{R}^k\) of the \(C\) subcomponents are concatenated into a matrix \(H^l(x) \in \mathbb{R}^{C \times k}\),
with no positional encoding.
These activations are projected into the transformer residual stream through a learned linear projection. The resulting representations are then processed by a standard transformer block consisting of a single attention head,
a feed-forward network, residual connections, and layer normalization.

Finally, each subcomponent representation is projected down to a single scalar, and a softmax over all C subcomponents is computed.
This produces a normalized assignment over subcomponents, $\sum_{c=1}^{C}g^l_c(x) = 1$,
causing the original minimality loss to become degenerate, as each layer contributes a constant value independent of the model state.
Instead, it is replaced
with entropy, to pressure the assignment to concentrate on as few subcomponents as possible. 
\begin{equation}
    \mathcal{L}_{\text{minimality}} = - \frac{1}{|L|} \sum_{l=1}^{L} \sum_{c=1}^{C} g^l_c(x) \log g^l_c(x)
\end{equation}

An unfortunate limitation of this formulation is its computational cost. Computing
relational importance via a transformer over subcomponents scales
quadratically with the number of subcomponents compared to the linear cost of the original independent importance functions.

\subsection{Toy Model of Superposition}
\label{sec:tms-experiments}

The Toy Model of Superposition (TMS) \autocite{elhage2022toymodelssuperposition} is trained to reconstruct sparse vectors through a lower-dimensional bottleneck that forces the model to learn features in superposition. The architecture is a single-hidden-layer autoencoder with tied weights:
\begin{equation}
    \hat{x} = \mathrm{ReLU}(W^{\top}Wx + b), \qquad W \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{in}}}, \quad d_{\text{in}} \gg d_{\text{hidden}}.
\end{equation}
TMS is studied in two regimes: one with independent inputs, reproducing the original SPD setup, and one with paired inputs that introduces statistical dependence. For both regimes, the rank of each subcomponent is kept at $1$, both because this is the ground-truth structure and to isolate the effect of softmax and attention.

To quantify how well the learned subcomponents recover the target model, two metrics are computed across both regimes. The mean max cosine similarity (MMCS) \autocite{cunningham2023takingfeatures} measures directional alignment between each target feature and its best-matching learned subcomponent:
\begin{equation}
\text{MMCS}
=
\frac{1}{d_{\text{in}}}
\sum_{j=1}^{d_{\text{in}}}
\max_{c}
\left(
\frac{
\vec{U}_{:,c} V_{c,j} \cdot W_{:,j}
}{
\left\| \vec{U}_{:,c} V_{c,j} \right\|_2
\left\| W_{:,j} \right\|_2
}
\right).
\end{equation}
where $c \in C$ is the parameter component index and $j \in \{1, \ldots, d_{\text{in}}\}$ is the input index. A value of $1$ indicates that every target feature has a perfectly aligned subcomponent.

Apart from directional alignment, the strength of the alignment is also measured, to detect feature shrinkage, a problem apparent in both Sparse Autoencoders and Attribution-Based Parameter Decomposition \autocite{jermyn2024tanhPenaltyDictionaryLearning,wright2024featureSuppressionSAEs,AttributionBasedParameterDecomposition}. The mean $L_{2}$ ratio (ML2R) compares the euclidean norm of the best-aligned subcomponent to the target feature \autocite{stochasticparameterdecomposition}:
\begin{equation}
\text{ML2R}
=
\frac{1}{d_{\text{in}}}
\sum_{j=1}^{d_{\text{in}}}
\frac{
\left\| \vec{U}_{:,\mathrm{mcs}(j)} \vec{V}_{\mathrm{mcs}(j),j} \right\|_2
}{
\left\| W_{:,j} \right\|_2
}
\end{equation}
where $\mathrm{mcs}(j)$ is the index of the most aligned subcomponent for feature $j$. A ratio near $1$ indicates the feature is fully captured by its best-aligned subcomponent.

\subsubsection{Paired features}
\label{sec:tms-tied-experiment}

To introduce the simplest form of statistical dependence, inputs are
sampled in pairs. The $d_{\text{in}} = 40$ inputs are partitioned into
$20$ pairs $\{f_{2i-1}, f_{2i}\}_{i=1}^{20}$, with $d_{\text{hidden}} = 10$.
Each pair is jointly inactive with probability $1-p$, and otherwise both
members are drawn independently from $\mathcal{U}(\epsilon, 1)$, with zero
reserved to denote the off state. The two members of a pair therefore
co-occur, switching on and off together, while their magnitudes remain
independent when active.

In this setting, each input is 2-dimensional at construction,
but the trained model learns a feature mapping that aligns both pair

similarity averaging $0.053$. The pair's hidden representation therefore
collapses to a 1D subspace. As each
pair is represented along a single direction, it can be captured by a single
rank-one subcomponent, without being split across several or requiring a
higher rank.

\subsection{Toy Model of Compressed Computation}
\label{sec:tcc-experiment}
The Toy Model of Compressed Computation, already studied by SPD
\autocite{stochasticparameterdecomposition}, APD
\autocite{AttributionBasedParameterDecomposition}, and more recently by
\autocite{bhagat2025compressed}, is trained to compute the elementwise function
$y_i = x_i + \mathrm{ReLU}(x_i)$ through a residual MLP with a lower-dimensional
hidden representation.

The architecture consists of an embedding matrix $W_E$, an unembedding matrix
$W_U = W_E^\top$, and a residual MLP with input projection
$W_{\text{in}} \in \mathbb{R}^{50 \times d_{\text{emb}}}$ and output projection
$W_{\text{out}} \in \mathbb{R}^{d_{\text{emb}} \times 50}$. The input vectors are
sparse activations sampled uniformly over $[-1, 1]$, and the model is trained to
minimise the MSE between its output and the target function:
\[
    y = W_U \big( W_E x + W_{\text{out}}(\mathrm{ReLU}(W_{\text{in}} W_E x)) \big).
\]
For comparability with previous work, the experiment uses $d_{\text{features}} = 100$,
$d_{\text{MLP}} = 50$, rank $k=1$ matrices, $C = 200$ subcomponents, and an
embedding dimension $d_{\text{emb}} = 1000$.

\begin{figure}[H]
    \centering
    \includegraphics[width=15cm, height=5cm]{CCmodel.png}
    \caption{Architecture of the Toy Model of Compressed Computation. Picture taken from \autocite{bhagat2025compressed}}
\end{figure}

A naive optimization would assign each hidden neuron to one of the $100$ ReLU
functions, but this would perform poorly on the remaining features. Instead, to
minimize the loss, the model approximates all $100$ computations jointly
\autocite{bhagat2025compressed}.

The ground truth for $W_{\text{in}}$ follows directly, where one subcomponent should be
causally important for one input feature, matching the independent
one-dimensional structure of the inputs. For $W_{\text{out}}$ it is less clear.
APD \autocite{AttributionBasedParameterDecomposition} initially expected a
monosemantic decomposition, with each subcomponent responsible for one of the
$100$ ReLU computations, while SPD \autocite{stochasticparameterdecomposition}
reports a polysemantic one, in which $50$ subcomponents each contribute to
multiple features and the rest are pruned to near-zero norm,
which is most in line with the result of \autocite{bhagat2025compressed},
and is most likely the correct interpretation.

To examine whether this assignment reflects the underlying decomposition, the
neuron-level contributions of the subcomponents are compared to those of the
target model \autocite{stochasticparameterdecomposition}.

\begin{align}
    \text{NeuronContribution}_{\text{model}}(i) &= \left( W_{U[i,:]}W_{\text{out}} \right) \odot \left( W_{\text{in}}W_{E}[:,i] \right) \label{eq:neuroncontribution} \\
    \text{NeuronContribution}_{\text{subcomponent}}(i) &= \max_{c \in C} \left[\left( W_{U[i,:]} U_{\text{out}} V_{\text{out}}^{T} \right) \odot \left(U_{\text{in}[:,c]}V^{T}_{\text{in}}[c,:] W_{E}[:,i] \right) \right] \label{eq:subcomponentcontribution}
\end{align}
where $W_{E[:,i]}$ and $W_{U[i,:]}$ are the $i$-th column and row of the embedding
and unembedding matrices, and $\odot$ denotes element wise multiplication. The term
$W_{U[i,:]}W_{\text{out}}$ measures how strongly the neurons contribute to the
output, and $W_{\text{in}}W_{E}[:,i]$ how strongly they are activated by input
$i$. A neuron contributes to feature $i$'s computation only when both are large;
if either is small, its contribution is negligible.

Despite the concentrated importance, the decomposition
decomposed subcomponents attribute one subcomponent
to each feature and the same neurons are involved in computing each feature as in the target model,
 but the contribution strength is misaligned, with some hidden neurons being underrepresented and others overrepresented. 
 (Figure~\ref{fig:cc_contribution}).
This is consistent with the lower ML2R seen in TMS and paired TMS, and occurs even
though the faithfulness and reconstruction losses are near-zero.

\subsection{Toy Model of Geometry}

In the paired TMS regime, even though input features were nominally two-dimensional, the model collapsed them onto a single direction, so a rank-1 decomposition per feature was sufficient. To test the rank-$k$ extension of Section~\ref{sec:rank-k-attention}, a setting is needed where features can not collapse to a single direction.
This experiment generalizes the cube example from the introduction, where a model is trained to compute the volume of an $n$-dimensional simplex from its $n+1$ vertices in $\mathbb{R}^n$:
\begin{equation}
    \text{Vol}(v_1, \ldots, v_{n+1}) = \frac{1}{n!} \left| \det\!\left( \begin{bmatrix} v_2 - v_1 & v_3 - v_1 & \cdots & v_{n+1} - v_1 \end{bmatrix} \right) \right|.
\end{equation}


To mirror the paired-feature setup of Section~\ref{sec:tms-tied-experiment}, the model receives $K$ simplices as input, each sampled with probability $p$ and otherwise set to zero across all of its coordinates:
\begin{equation}
    f(x) = W_2 \text{ReLU}(W_1 x), \quad W_1 \in \mathbb{R}^{d_{\text{hidden}} \times K n(n+1)}, \quad W_2 \in \mathbb{R}^{K \times d_{\text{hidden}}},
\end{equation}
here $n(n+1)$ is the total number of coordinates of a simplex in $\mathbb{R}^n$ and $K$ is the number of simplices.
Concretely, for this experiment the simplices are triangles in $\mathbb{R}^2$, with $K = 3$ and $d_{\text{hidden}} = 150$.

Unlike TMS, $d_{\text{hidden}}$ is chosen to be much greater than the input dimension (here $d_{in}= 18$), so that the model does not need to compress features through superposition.
The intention being that the model assigns each simplex to a
separate subset of neurons, allowing the routing of information
from input to output to be studied in isolation, as the minimality
loss is applied at different strengths and as the rank
is increased.


\subsubsection{Target model structure}
To examine, how the model learns to compute the volume,
a similar approach to that of Section \ref{sec:tcc-experiment} is adopted.
The routing strength from each simplex to each output is measured by
decomposing the preactivations of the hidden neurons into contributions
from each simplex, and then measuring how strongly those neurons contribute
to the output.

Concretely, two quantities are defined over the hidden neurons.
Firstly, how strongly each simplex influences a hidden neurons state,
secondly how strongly each hidden neuron contributes to the volume output of each simplex,

Let the input vector be partitioned \footnote{input vector good word, but we should write a vector notation too} into $K$ disjoint groups,
where group $g$ contains the column indices for the $n(n+1)$ coordinates of simplex $g$ denoted
by $\mathcal{C}_g$, with the groups jointly covering all input columns.

Let $W_g^{l}$ denote $W^{l}$ restricted to the columns in $\mathcal{C}_g$
and zero elsewhere, such  that $W^{l} = \sum_{g=1}^{K} W^{l}_{g}$.

Each simplex routes through its own disjoint
set of hidden neurons, so the first layer decomposes
into independent subcomponents, one per simplex.
The grouping in the second layer was less obvious,
as it seemed equally possible that a single set of subcomponents
computes the volume for all three simplices, or that each simplex
is assigned its own. The decomposition points to the latter,
with each simplex's computation captured by a separate set
of subcomponents across both layers.
Unlike the paired TMS feature, a simplex's computation
is spread across a higher dimensional space,
and is not collapsible into a single direction, that
a single rank-1 subcomponent could capture. 

Whether the decomposition method
recovers the ground-truth structure inside a set of rank one subcomponents,
or a single higher dimensional subcomponent that captures the entire simplex,
should depend on two factors: the dimensionality each
subcomponent is allowed to represent, and how strongly
the minimality loss penalises spreading importance
across multiple subcomponents. As these parameters are
varied, the recovered decomposition is expected to
change gradually: a subcomponent may capture progressively
larger fractions of a single simplex, converging towards
the ground-truth decomposition. Alternatively, the additional
capacity may be used to represent parts of multiple simplices
simultaneously, resulting in a decomposition that mixes otherwise
reducible computations.


To isolate the effect of the subcomponent rank from that of the minimality coefficient,
the two factors are varied one at a time. First, the rank is fixed at $k=1$, recovering the
original SPD formulation, and the minimality coefficient $\beta_3$ is varied to examine its
influence on the decomposition. Second, $\beta_3$ is fixed at a value that produced a clear
decomposition at $k=1$, and the rank is increased to examine how higher $k$ allows different
decompositions to be recovered.

\subsubsection{Subcomponent structure}
To examine the structure of the target model, the hidden neurons were the unit of analysis \footnote{unit of analysis sounds dumb as hell}. To see
how the decomposition realises this, the same quantities are redefined over the subcomponents,
measuring how strongly they route into one another across all hidden neurons.

Let $W^{l}_{(c)}$ be a subcomponent of layer $l$, defined in the same manner as in Section $\ref{sec:rank-k-attention}$,
such that $\sum_{c=1}^{C} W^{(l)}_{(c)} \approx W^{l}$.
Then, analogous to the definitions above, the additive contribution of simplex \(g\) to hidden neuron \(i\), and the contribution of hidden neuron \(i\) to output \(k\), through subcomponent \(c\), are given by
\begin{equation}
\begin{aligned}
    \rho^{\,l}_{(c),[i,g]}
    &:= \sum_{j \in \mathcal{C}_g} W^{(l)}_{(c),[i,j]},
    &\qquad
    \rho^{\,l}_{[i,g]}
    &= \sum_{c=1}^{C} \rho^{\,l}_{(c),[i,g]}, \\
    \pi^{(c)}_{l+1,[k,i]}
    &:= W^{(l+1)}_{(c),[k,i]},
    &\qquad
    \pi_{l+1,[k,i]}
    &= \sum_{c=1}^{C} \pi^{(c)}_{l+1,[k,i]} .
\end{aligned}
\end{equation}
Finally, since the subcomponents can be linked through multiple hidden neurons, their total routing
across all hidden neurons is measured. The routing matrix $\Psi \in \mathbb{R}^{|C|\times|C|}$ is
defined as the inner product over the hidden neurons between the total input read by $c$ and the total
output written by $c'$ at each neuron.
\begin{equation}
    \Psi_{c',c} := \sum_{i=1}^{d_{\text{hidden}}}
    \left( \sum_{k=1}^{d_{\text{out}}} W^{(l+1)}_{(c'),[k,i]} \right)
    \left( \sum_{j=1}^{d_{\text{in}}} W^{(l)}_{(c),[i,j]} \right),
\end{equation}
It is large when the neurons $c$ activates from the input
are the ones $c'$ uses to write the output, indicating a shared hidden representation.
The form follows from the linear composition of the two subcomponents: ignoring the ReLU, the
path through $c$ at layer $l$ and then $c'$ at layer $l+1$ is $W^{(l+1)}_{(c')} W^{(l)}_{(c)}$,
and $\Psi_{c',c}$ is the sum of its entries. The ReLU makes this approximate, so $\Psi$ is read
as a linearised measure of routing from $c$ into $c'$.

These three quantities together describe the routing through the decomposition. The input
contribution $\rho^{(c)}_{l,[i,g]}$ shows how each simplex group contributes to subcomponent $c$,
the output contribution $\pi^{(c)}_{l+1,[k,i]}$ shows how subcomponent $c$ contribute to each output,
and the routing matrix $\Psi_{c',c}$ composes the two, measuring how strongly a subcomponent that
reads from the input ($c$) connects to one that writes to the output ($c'$) through shared
hidden neurons.

\subsubsection{Comparison of importance values across different minimality coefficients}
With the rank fixed at $k=1$, the minimality coefficient $\beta_3$ is
varied in order to compare how SPD and the softmax variant distribute importance
under different levels of pressure toward sparsity.
Since a rank-1 subcomponent
can not represent a full simplex, the focus lies in
how each method allocates importance across subcomponents, when
the capacity is insufficient.



In SPD, when the minimality coefficient is set to $\beta_3 = 10^{-3}$, the minimality loss dominates and
almost all importance is suppressed, so no usable decomposition is recovered. As $\beta_3$ is
relaxed the expected structure emerges, clearest around $\beta_3 = 10^{-5}$. The
coordinates of each simplex become important for a distinct block of subcomponents, with
negligible importance on the subcomponents of the other simplices. The recovered grouping
reproduces the hypothesized ground-truth decomposition at the level of simplices.
Within each group, however, importance over individual coordinates is spread across multiple simplices,
as expected at $k=1$, where a rank-one subcomponent can not on its own represent a
simplex's volume. For $\beta_3 = 10^{-6}$ and below, this grouping dissolves and
individual subcomponents become important for several simplices at once, mixing the otherwise
independent computations. For the second layer, when $\beta_{3}$ is set to $10^{-5}$,
one subcomponent become causally important for each simplex, recovering the hypothesized
decomposition. (Figure \ref{fig:spd_minimality_sweep_condensed}).

For Softmax, the same sweep yields very different results. At $\beta_3 = 10^{-3}$ the decomposition finds
a near-diagonal representation, with each subcomponent causally important for a single coordinate
of one simplex. Lowering $\beta_3$ towards $\beta_{3}=10^{-5}$ makes subcomponents causally important for multiple coordinates of the same simplex,
with some becoming causally important for different simplices, most notable in simplex 2 and 3. The pattern starts to break down at $\beta_3 = 10^{-6}$,
where the minimality loss no longer penalises spreading importance across subcomponents strongly
enough. In the second layer the model recovers the alternative decomposition hypothesised earlier,
in which a single subcomponent is causally important for all three simplices. (Figure \ref{fig:softmax_minimality_sweep_condensed}).

\subsubsection{Comparison of importance values across ranks at fixed minimality}

Increasing the rank raises each subcomponent's representational capacity
(Section~\ref{sec:rank-k-attention}), so a single higher-rank subcomponent could in principle
absorb an entire simplex. Capacity alone, however, does not enforce this: SPD's independent sigmoid
gating imposes little pressure for a feature to be carried by one subcomponent rather than spread across
several, so the added rank can instead be used to represent parts of multiple simplices at once.
Softmax is instead conditioned to capture the entire input feature and should have sufficient 
structural pressure to achieve this.

From the previous section, a minimality coefficient of $10^{-5}$ is selected for SPD, as it
minimises the global loss while producing the clustering that
best resembles the expected decomposition. For Softmax it is set to $10^{-3}$,
as it minimized the loss.

Structurally the causal importance values for SPD, do not show this desired behaviour as the rank is increased,
instead as each subcomponent becomes more expressive, the total number of active subcomponents
decreases, with each now being causally important for multiple simplices. This however does not entangle 
the importance of the second layer, where one subcomponent remains active for each simplex.

For softmax, the causal importance assignment does show the desired trend,
as the rank increases one subcomponent gradually becomes causally important for one simplex
in the input layer, while in the output layer, the same behaviour is seen as with the minimality sweep,
where one subcomponent becomes causally important for all three simplices, with the remaining subcomponents being inactive.

\section{Discussion}

In every experiment, both SPD and the Softmax variant reached near-zero faithfulness loss and
reconstructed the layer outputs accurately. The two methods nonetheless have very different
internal structures, and the central finding of this work is that a sparse causal importance
assignment does not imply a sparse underlying representation with the modified softmax and attention structure.

The softmax variant repeatedly produced concentrated, near one-hot importance values that did not
correspond to an equally concentrated representation. In the Toy Model of Compressed Computation,
the one-hot assignment suggested a monosemantic decomposition, yet at the neuron level each
subcomponent contributed to several of the ReLU computations, including ones for which it carried no
causal importance.\footnote{Again remember to double check with a fully trained model.} In the
geometric experiment the importance values likewise suggested a clean per-simplex assignment, but
the routing analysis showed subcomponents reading from multiple simplices and, in the second layer,
writing to several simplex outputs at once, mirroring the compressed-computation result. Even in the
independent Toy Model of Superposition, where SPD and softmax produced the same one-hot importance
assignment, softmax diverged on both MMCS and ML2R, recovering a slightly rotated geometry with
residual magnitude spread across neighbouring features.

It was initially hypothesised that normalising the importance distribution would tie it directly to
the magnitude of each subcomponent, so that a subcomponent's predicted importance and its share of
the reconstruction would correlate. This did not hold. The entropy term does not drive the norm of
inactive subcomponents to zero; they remain residually active and continue to contribute to the
reconstruction, so the one-hot importance overstates how cleanly a feature is owned by a single
subcomponent. This probably isn't the sole cause however,
in VPD the importance prediction was generally found to be too weak,
and that subcomponents should not jus be causally important,
when all other weights are ablated, but should be causally important
in every subset that includes them. \footnote{added something here}



A natural explanation would be that the softmax can not emit hard zeros, but the
near-bimodal distribution of importance values rules this out: the importance values themselves do
reach zero, while the norms of the corresponding subcomponents retain a tail of meaningful
magnitude. The cause therefore seems not to be attributed to how the importance is distributed,
but rather in how reconstruction
mass is allocated across subcomponents during optimisation, to which the additive faithfulness
objective is indifferent. This came as a bigger surprise, as SPD also only penalises
the norm distribution indirectly through the minimisation of the total
importance, yet it does drive the norms of inactive subcomponents to near-zero.

Taken together, the softmax formulation does not appear to be the right tool for parameter
decomposition in its current form. This is clearest in the compressed-computation model, where the
target feature is an approximation of many computations at once and can not be attributed to a single
direction in superposition; forcing a one-hot assignment is then 
counterproductive. The
sampling comparison points the same way: softmax converged far better, 
under one-hot sampling, where a single subcomponent could plausibly own each active
feature. Entropy with softmax, is therefore better suited to settings where
there is a binary measure of importance,  whereas the right target is more
likely a continuum between the two \autocite{bushnaq2026interpreting_new_spd}.



In the Toy Model of Geometry,
SPD recovered a clustered representation that
matched the per-simplex grouping of the ground truth,
but increasing the subcomponent rank did not
let it absorb a whole simplex into one subcomponent.
Instead the added capacity was spent sharing
simplices across a smaller set of subcomponents,
since neither the sigmoid gating nor the minimality
loss exerted sufficient pressure for a feature to
be owned by one subcomponent rather than spread across
several subcomponents. Therefore if SPD
is supposed to recover these features and work with a 
higher representational capacity, future work
should investigate alternative designs, that could enforce this structural pressure.

The rank constraint connects to a different ambiguity
about what structure parameter decomposition is meant to
recover. In the SPD formulation the rank-one constraint
is intended to enforce the simplicity of a
mechanism, but rank-one is not the smallest possible unit.
Two otherwise independent features can be
aligned along a common direction
and captured by a single rank-one subcomponent, if they happen to correlate, \footnote{Wording here, independent and correlate are somewhat contradicting}
which is exactly what was observed in the paired TMS setting, where one rank-one subcomponent
captures a feature pair just as it would a single feature. In that sense one decomposition is
strictly coarser than the other, yet both are rank-one and both reconstruct the model, so rank alone
does not determine simplicity. While it did align with the behaviour specified by the irreducibility condition in this case,
the concept is not unique to TMS. The same pattern appears in VPD, where a toy model implements multiple 
mechanisms with disjoint support that sum to a single rank-one matrix. 
\autocite{bushnaq2026interpreting_new_spd}.
Therefore, choosing whether to increase the rank is not a trivial decision, as each option entails distinct trade-offs in expressivity and interpretability



\section{Limitations and future work}

Beyond the limitations already noted, this work has a few primary shortcomings.

The comparison conflates two changes at once.
The original method computes each subcomponent's
importance independently with a small MLP, whereas
the architecture used here computes importance
relationally, through a transformer block with
a softmax over subcomponent activations. It is
therefore not possible to attribute the observed
differences to either change in isolation.
In concurrent work, the change to implement a transformer
to compute relational importance has been implemented
with good success, so it is likely that the observed
differences can be attributed to softmax.
\autocite{bushnaq2026interpreting_new_spd} 

From the perspective of irreducibility, the experiments
do not test whether a subcomponent is in its atomic state,
or whether it could be split further. Further work should
investigate how to test this, for instance by applying
the proposed feature-discovery algorithm in \autocite{engels2025languagemodelfeaturesonedimensionally} to the recovered subcomponents.
Additionally it should be investigated if these features should instead
be split into separate subcomponents, to disentangle scenarios, where 
collinear features with disjoint support are captured by a single subcomponent. \autocite{bushnaq2026interpreting_new_spd}

Finally, every setting studied here is a toy model with a known ground-truth decomposition. The
methods have not been tested on larger systems,
where the true decomposition is unknown, which is
ultimately where a parameter-decomposition method must prove useful. This is compounded by a strong
sensitivity to hyperparameters, in particular the minimality coefficient and the subcomponent rank,
which were tuned against the known ground truth.

% Because the simplices are reducible across groups but irreducible within, the ground-truth
% decomposition can be reasoned out layer by layer. In the first layer, $W_1$ should split into $K$
% subcomponents, one per simplex, where subcomponent $g$ reads only the $n(n+1)$ coordinates of simplex
% $g$ and writes to the hidden neurons dedicated to it. As these coordinates are irreducible they
% should not be split further, so each simplex occupies a single first-layer subcomponent, and this
% subcomponent must have rank greater than one, since the volume can not be computed along a single
% direction. In the second layer, $W_2$ should likewise split into $K$ subcomponents, where
% subcomponent $g$ reads simplex $g$'s hidden neurons and writes its volume to output $g$. Each simplex
% is therefore realised as a matched pair, the first-layer subcomponent that reads its coordinates
% feeding the second-layer subcomponent that writes its volume, so the routing matrix $\Psi$ should be
% block diagonal with one path per simplex. Being reducible, distinct simplices form $K$ such
% independent paths.

% ground-truth structure of $W_{\text{out}}$ is genuinely ambiguous, and is unnecessary for TMS, whose
