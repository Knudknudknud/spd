\section{Introduction}

Mechanistic interpretability seeks to reverse-engineer neural
networks into a set of human-interpretable mechanisms.
Different branches of the field pursue this goal with different focal points: Either through directions in activation space, computational subgraphs, or components of the network's parameters.

However, both the atomic structure for decomposition
 and the decomposition itself remain open problems.
\autocite{sharkey2025openproblemsmechanisticinterpretability}
Whether a decomposition recovers the computational primitives
of a neural network depends on what the ground-truth decomposition
is taken to be. With models consisting of independent features,
the decomposition is unambiguous, with one atom per feature.
If the features are dependent or co-occur, the decomposition becomes underdetermined.
Decompositions that split features across multiple atoms, risk losing the structural information, that gives each feature its meaning,
while decompositions that group multiple features into a single atom, risk losing granularity by collapsing distinct features into a single unit.

For example, a network computing the volume of a cube can be
decomposed into components corresponding to individual side
lengths, or into a single component computing the volume directly.
The former corresponds to a feature-level decomposition,
with one atom per input direction, exposing internal
structure but leaving grouping implicit, only recoverable
through co-activation patterns. The latter corresponds
to a structural-level decomposition, with one atom per
computation, exposing the grouping directly but collapsing per side-length information.

\section{Related work}
\subsection{The linear representation hypothesis}
A widespread view in mechanistic interpretability is the linear representation hypothesis: high-level concepts are encoded as directions in a network's representation space \autocite{park2024linearrepresentationhypothesisgeometry}. Together with the superposition hypothesis \autocite{elhage2022toymodelssuperposition}, it forms a central tenet of interpretability: each feature corresponds to a single direction, and a hidden state is a sparse linear combination of feature directions.

Recent work questions how strictly this view should be taken, distinguishing between a weak form of the hypothesis, that some features are linear, from a stronger form that all features are \autocite{mendel2024sae,smith2024strong}. 
Empirically multiple counterexamples to the stronger form have been proposed, include recurrent networks encoding token position by magnitude rather than direction \autocite{csordás2024recurrentneuralnetworkslearn}, transformers representing cyclical concepts such as days of the week \autocite{engels2025languagemodelfeaturesonedimensionally} or modular arithmetic \autocite{nanda2023progressmeasuresgrokkingmechanistic} in irreducible low-dimensional subspaces.
\subsection{Activation-space decomposition}
Decomposing a network's activations predominantly focuses on disentangling layer activations into interpretable features.
Here, sparse autoencoders (SAE) are one of the most widely researched methods \autocite{sparseautoencodershighlyinterpretable, bricken2023monosemanticity},
that learn an overcomplete dictionary that expresses each hidden state as a sparse combination of one-dimensional features.
However, these features are not necessarily aligned with the network's computation, due to feature absorption, inconsistencies across dictionary sizes, and a failure to capture feature geometry.
 \autocite{absorptionstudyingfeaturesplitting, sparseautoencoderscanonicalunits,mendel2024sae}.

Circuit discovery extends feature analysis to identify
how a computation is processed by the network's structure,
by identifying  minimal subgraphs required to perform a given task,
without loss of performance. \autocite{olah2020zoomin,marks2025sparsefeaturecircuitsdiscovering}.
However, these methods generally do not account for the
polysemantic and densely connected structure of neural networks,
where the functional behaviour can be attributed to multiple distinct but functionally equivalent subgraphs \autocite{méloux2025everythingeverywhereoncemechanistic}.

\subsection{Parameter-space decomposition}

Recently a newer line of work aims to decompose the network's parameters directly, instead of the activations.
Transcoders \autocite{dunefsky2024transcodersinterpretablellmfeature} represent an intermediate step that learns a sparse approximation of an MLP layer. Parameter decomposition methods go further, factorising the network's weights directly, with the goal of recovering the network's computational primitives.

Most directly relevant to this work is the description-length-driven
line of Attribution-based Parameter Decomposition
\autocite{AttributionBasedParameterDecomposition} and
Stochastic Parameter Decomposition (SPD)
\autocite{stochasticparameterdecomposition}, which has
recently been explored in small transformer models
\autocite{christensen2025decompositionsmalltransformermodels}
and cross-layer clustering \autocite{seshadri2026crosslayer}.
While APD decomposes a network into multidimensional
components,
the method is sensitive to hyperparameters, and does not scale beyond toy settings due
to computational complexity. SPD addresses this
by decomposing each weight matrix into rank-one
subcomponents and learning a per-input importance
function over them, at the cost of requiring post-hoc
clustering to recover higher-rank mechanisms;
both methods are detailed in
Section~\ref{sec:spd_background}. Other parameter-space
approaches include local loss landscape decomposition \autocite{chrisman2025identifyingsparselyactivecircuits}.



\section{Method}

\subsection{Background on SPD}
\label{sec:spd_background}
Attribution-based Parameter Decomposition (APD) \autocite{AttributionBasedParameterDecomposition}
and Stochastic Parameter Decomposition (SPD) \autocite{stochasticparameterdecomposition} both aim to decompose
a network's parameters into a set of components that are faithful
to the original weights, minimal in the number required per input,
and individually as simple as possible.

To formalise this, consider a neural network $f(x, W)$ with weight matrices $W = \{W^1, \dots, W^L\}$.
A set of parameter components $\{W^l_c\}_{c=1}^{C}$ are said to comprise the network's mechanisms if they satisfy the following properties:
\renewcommand\labelitemi{\tiny$\bullet$}
\begin{itemize}
    \setlength\itemsep{0em}
    \item \textbf{Faithfulness}: The parameter components should sum to the 
          parameters of the original network.
    \item \textbf{Minimality}: As few parameter components as possible should 
          be required to replicate the network's output on any given input.
    \item \textbf{Simplicity}: Each component should span as few weight 
          matrices and as few ranks as possible.
\end{itemize}

APD \autocite{AttributionBasedParameterDecomposition} approaches this by decomposing
the network into a set of parameter components without constraining
their rank, using a gradient-based attribution that selects the top-$k$ components most
responsible for any given input. While effective on small models,
APD scales poorly: its memory cost grows with the number of components,
as each component has the same dimensionality as the original network,
and its top-$k$ attribution is sensitive to hyperparameter choice.

SPD \autocite{stochasticparameterdecomposition} addresses these limitations by enforcing a rank-one structure on each component, allowing more components to be learned at fixed memory cost, and replacing top-$k$ attribution with a learned causal importance function. Formally, each weight matrix $W^l$ is decomposed into a sum of $C$ rank-one subcomponents:
\begin{equation}
W^{l}_{i,j} \approx \sum_{c=1}^{C} U^{l}_{c,i} V^{l}_{c,j}, 
\quad \text{where} \quad U^l \in \mathbb{R}^{C \times d_{\text{out}}}, \, V^l \in \mathbb{R}^{C \times d_{\text{in}}}
\end{equation}
where C is a hyperparameter, for the number of components for each layer, $l$ indexes the layer and $i,j$ are the hidden indices.
The subcomponent count, C, may be chosen to be larger than both $d_{in}$ and $d_{out}$, enabling the method to learn features in superposition \autocite{stochasticparameterdecomposition}.

To enforce the properties above, three losses are introduced, which are optimised jointly.
Faithfulness is enforced thorugh a mean squared error loss between the original network's weights and the the sum of subcomponents:

\begin{equation}
    \mathcal{L}_{\text{faithfulness}} = \frac{1}{N} \sum_{l=1}^{L}\sum_{i,j} \left( W_{i,j}^{l} - \sum_{c=1}^{C} U^{l}_{i,c}V^{l}_{c,j} \right)^{2}  
\end{equation}
where $N$ is the total parameter count in the target model.

Optimization for simplicity and minimality is achieved through a
stochastic masking procedure. Intuitively, if a subcomponent is not
necessary for reconstruction, it can be sampled to zero without loss
of faithfulness. A causal importance function
$\Gamma: \mathcal{X} \to [0,1]^{C \times L}$ is trained to learn the
lower bound of the sampling distribution. In SPD, $\Gamma$ is a set
of independent MLPs $\gamma^l_c$ that each take a layer's activation
and output a scalar importance for the corresponding subcomponent:
\begin{equation}
g^{l}_{c}(x) = \Gamma^l_c(x) = \sigma_{H}(\gamma^{l}_{c}(h^{l}_{c}(x))), \qquad h^{l}_{c}(x) = \vec{V}_{c}^{l\top} \vec{a}^l(x)
\end{equation}
where $\sigma_{H}$ is a hard sigmoid and $\vec{a}^l(x)$ is the
activation at layer $l$. These importance values serve as the lower bound for how much a subcomponent can be masked. With $r^l_{c} \sim \mathcal{U}(0, 1)$ sampled per subcomponent, the masked weight matrix is given by:
\begin{equation}
\begin{aligned}
    m_{c}^l(x, r) &= g^{l}_{c}(x) + \bigl(1 - g^{l}_{c}(x)\bigr)\, r^l_{c}, \\
    W'^{l}(x, r)  &= \sum_{c=1}^{C} \vec{U}_{i,c}^{l}\, m_{c}^l(x, r)\, \vec{V}_{c,j}^{l},
\end{aligned}
\end{equation}
These masked matrices are trained to reconstruct the original network's output.
\begin{equation}
    f\!\left(x \,\big|\, \{W'^{l}(x, r)\}_{l=1}^{L}\right)
    \approx
    f\!\left(x \,\big|\, \{W^{l}\}_{l=1}^{L}\right).
\end{equation}
This is done through both a layer-wise and a global reconstruction loss. The layer-wise version is necessary to provide a stronger training signal as randomly masking all components at the same time can be too noisy to learn from.

\begin{equation}
\begin{aligned}
    \mathcal{L}_{\text{stochastic-recon}}
      &= \frac{1}{S} \sum_{s=1}^{S}
         D\!\left(f\bigl(x \mid W'(x, r^{s})\bigr),\; f(x \mid W)\right), \\
    \mathcal{L}_{\text{stochastic-recon-layer}}
      &= \frac{1}{LS} \sum_{l=1}^{L} \sum_{s=1}^{S}
         D\!\left(f\bigl(x \mid W^{1}, \dots, W'^{\,l}(x, r^{(s)}), \dots, W^{L}\bigr),\;
                  f(x \mid W)\right).
\end{aligned}
\end{equation}
where $D$ is a task-specific divergence measure, such as MSE or KL divergence.

Lastly, to enforce minimality, the importance function is
trained to activate only the subcomponents needed for reconstruction.
The loss balances reconstruction accuracy against the number of active
subcomponents, creating a tradeoff between faithfulness and
minimality. The goal is to activate only the subcomponents required
to reproduce the target model's output while leaving the rest inactive.
\begin{equation}
    \mathcal{L}_{\text{minimality}}
      = \sum_{l=1}^{L} \sum_{c=1}^{C} \bigl(g^{l}_{c}(x)\bigr)^{p},
      \qquad p > 0.
\end{equation}
\label{spd_minimality}

The full SPD objective is a weighted sum of these terms:
\begin{equation}
    \mathcal{L}_{\text{SPD}}
      = \mathcal{L}_{\text{faithfulness}}
      + \beta_{1}\, \mathcal{L}_{\text{stochastic-recon}}
      + \beta_{2}\, \mathcal{L}_{\text{stochastic-recon-layer}}
      + \beta_{3}\, \mathcal{L}_{\text{minimality}}.
\end{equation}

\subsection{Irreducibility and the natural unit of decomposition}
\label{sec:irreducibility}
To appropriately evaluate the performance of a multi-dimensional feature decomposition method,
it's necessary to have a clear definition of what the ground-truth decomposition is. The original
superposition hypothesis states that the hidden states can be represented as a linear combination of sparse one-dimensional features. \cite{elhage2022toymodelssuperposition,engels2025languagemodelfeaturesonedimensionally}

\textbf{Definition:} The hidden state 
$x_{i,l}$ can be written as:
\begin{equation}
    x_{i,l} = \sum_i v_i \, f_i(t)
\end{equation}
where $v_{i} \in \mathbb{R}^d$ are pairwise $\delta$-orthogonal directions \footnote{should i say what delta is or is it clear that its small?} and $f_{i}(t) \in \mathbb{R}$ are sparse scalar activations, with $f_{i}(t)=0$ outside the domain of feature $i$.

Recent work has shown, that this may be insufficiently strict \autocite{smith2024strong,engels2025languagemodelfeaturesonedimensionally}, as it does not capture the structure of multi-dimensional features.
In particular, transformer models are shown to
organise cyclical concepts in low-dimensional subspaces
that do not decompose into meaningful linear components, but are instead manipulated jointly \autocite{engels2025languagemodelfeaturesonedimensionally}.

To accomodate these features, the same paper proposes a correction to the superposition hypothesis,
alongside a formal definition of irreducibility that defines,
when a feature is in its atomic form and when it can be decomposed into smaller
units without loss of information.

\textbf{Definition:} A feature $f: \mathbb{R}^{i} \to \mathbb{R}^{d_f}$ is
truly multi-dimensional, if it cannot be written as a sum of two independent features
or as a the sum of two non-co-occurring features. More formally, a feature is
reducible into features
$a$ and $b$ if there exists an affine transformation
\begin{equation}
    f \mapsto Rf + c \equiv \binom{a}{b}
\end{equation}
for some orthonormal $d_{f} \times d_{f}$ matrix $R$, and additive constant c, such that
the joint distribution $p(a, b)$ satisfies one of two conditions:
\renewcommand\labelitemi{\tiny$\bullet$}
\begin{itemize}
    \setlength\itemsep{0em}
    \item \textbf{$p$ is separable}: $p(a, b)= p(a) \, p(b)$
    \item \textbf{$p$ is a mixture of two disjoint distributions}: 
    $p(a, b) = w \, p(a) \, \delta(b) + (1 - w) \, p'(a,b | b \neq 0)$,

\end{itemize}
Here $a$ and $b$ are the first $k$ and remaining $d_f - k$ components of $Rf + c$,
$p$ is conditioned on inputs where $f$ is active, $w \in (0, 1)$ and $\delta$ is the Dirac delta \footnote{can i get away with just writing $p(a|b=0)$}.
In the mixture, the two distributions have disjoint support, with one distribution having no mass where $b$ is active, and the other having no mass where $b$ is zero.

Under this decomposition, the superposition hypothesis takes the form:


\textbf{Definition:} Every hidden state $x_{i,l}(t)$ can be written as a sum of feature contributions
\begin{equation}
    x_{i,l}(t) = \sum_i V_i \, f_i(t)
\end{equation}
where each $f_i(t) \in \mathbb{R}^{d_{f_i}}$ is an irreducible
feature with internal dimensionality $d_{f_i} \geq 1$, each
$V_i \in \mathbb{R}^{d \times d_{f_i}}$ and $\| V_i^\top V_j \| < \delta$ for $i \neq j$.


Secondly, and more importantly for SPD, if the multidimensional
superposition hypothesis holds, some features f may require multiple
rank-one subcomponents. It is not trivial that an irreducible function
f (e.g. as shown in Section \ref{fig:tms-paired-comparison}) arises from sampling
two dependent and non-overlapping features that can still be compressed 
into a single rank-one component if the model learns to group them along a shared direction.

However, when the model learns genuinely multi-dimensional features,
these cannot in general be represented by a rank-one subcomponent.
Instead, they occupy structured higher-dimensional subspaces,
implying either the need for higher-rank representations or post hoc
clustering of the underlying rank-one components.

\subsection{Rank-$k$ subcomponents and relational importance}
\label{sec:rank-k-attention}
In the original SPD paper, the subcomponents are constructed as rank-one matrices, through an outer product of two vectors.
This formulation is however incompatible with the multi-dimensional superposition hypothesis. (Section \ref{sec:irreducibility})
A decomposition into lower-dimensional subcomponents, necessarily forces features to be split across multiple subcomponents, or to be approximated through a single subcomponent at the cost of reconstruction.

To represent multi-dimensional features, the pairs of vectors are replaced with pairs of matrices.
\begin{equation}
W^{l}_{i,j} \approx \sum_{c=1}^{C} \sum_{r=1}^{k} U^{l}_{c,i,r} V^{l}_{c,j,r},
\quad \text{where} \quad U^l \in \mathbb{R}^{C \times d_{\text{out}} \times k}, \, V^l \in \mathbb{R}^{C \times d_{\text{in}} \times k}
\end{equation}
Each subcomponent $U^l_c {V^l_c}^{\top} \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$
has rank at most $k$, recovering the original SPD definition when $k=1$.
As in the multi-dimensional superposition hypothesis, $k$ is an upper bound on
each subcomponent's representational capacity; the effective rank may be lower,

In SPD, each subcomponent’s importance is computed independently through an MLP followed by a sigmoid nonlinearity,
allowing multiple subcomponents to be active for a given input and thus distribute a
feature across them, even when it is irreducible. Likewise, the minimality loss does not translate to the rank-k setting, where each subcomponent can represent multiple feature directions:
it imposes no penalty for distributing a feature across multiple subcomponents,
nor for a single subcomponent to encode parts of multiple features. (Section \ref{spd_minimality})

To address this, the causal importance function is redefined to maximize the conditional probability, that a given subcomponent $W_{c}^{l}$, is responsible for a given feature, conditioned on the activations of all other subcomponents in the same layer.
\begin{equation}
    g^l_{c}(x) = p\!\left(W^l_c \mid \{h^l_{c'}(x)\}^{C}_{c'=1}\right), \quad h^l_c(x) = {V^l_c}^{\top} \vec{a}^l(x) \in \mathbb{R}^k
\end{equation}
where $\vec{a}^l(x)$ is the activation of layer $l$ and C is the set of subcompoennts in layer $l$.
The distribution is computed with a classic transformer block operating over subcomponents, with a softmax over their activations.
\autocite{vaswani2023attentionneed}

This produces a normalized assignment over subcomponents, $\sum_{c=1}^{C}g^l_c(x) = 1$,
causing the original minimality loss to become degenerate, as each layer contributes a constant value independent of the model state.
Instead, it's replaced
with entropy, to pressure the assignment to concentrate on as few subcomponents as possible. 
\begin{equation}
    \mathcal{L}_{\text{minimality}} = - \frac{1}{|L|} \sum_{l=1}^{L} \sum_{c=1}^{C} g^l_c(x) \log g^l_c(x)
\end{equation}

An unfortunate limitation of this formulation is its computational cost. Computing
relational importance via a transformer over subcomponents scales
quadratically with the number of subcomponents compared to the linear cost of the original independent importance functions.  \footnote{Play with attention approximations}

\subsection{Toy Model of Superposition}
\label{sec:tms-experiments}

The Toy Model of Superposition (TMS) \autocite{elhage2022toymodelssuperposition} is trained to reconstruct sparse feature activations through a lower-dimensional bottleneck that forces the model to learn features in superposition. The architecture is a single-hidden-layer autoencoder with tied weights:
\begin{equation}
    \hat{x} = \mathrm{ReLU}(W^{\top}Wx + b), \qquad W \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{features}}}, \quad d_{\text{features}} \gg d_{\text{hidden}}.
\end{equation}
TMS is studied in two regimes: one with independent features, reproducing the original SPD setup, and one with paired features that introduces statistical dependence. For both regimes, the rank of each subcomponent is kept at $1$, both because this is the ground-truth structure and to isolate the effect of softmax-and-attention.

To quantify how well the learned subcomponents recover the target model, two metrics are computed across both regimes. The mean max cosine similarity (MMCS) \autocite{cunningham2023takingfeatures} measures directional alignment between each target feature and its best-matching learned subcomponent:
\begin{equation}
\text{MMCS}
=
\frac{1}{d_{\text{features}}}
\sum_{j=1}^{d_{\text{features}}}
\max_{c}
\left(
\frac{
\vec{U}_{:,c} V_{c,j} \cdot W_{:,j}
}{
\left\| \vec{U}_{:,c} V_{c,j} \right\|_2
\left\| W_{:,j} \right\|_2
}
\right).
\end{equation}
where $c \in C$ is the parameter component index and $j \in \{1, \ldots, d_{\text{features}}\}$ is the input feature index. A value of $1$ indicates that every target feature has a perfectly aligned subcomponent.

Apart from directional alignment, the strength of the alignment is also measured, to detect feature shrinkage, a problem apparent in both Sparse Autoencoders and Attribution-Based Parameter Decomposition \autocite{jermyn2024tanhPenaltyDictionaryLearning,wright2024featureSuppressionSAEs,AttributionBasedParameterDecomposition}. The mean $L_{2}$ ratio (ML2R) compares the euclidean norm of the best-aligned subcomponent to the target feature \autocite{stochasticparameterdecomposition}:
\begin{equation}
\text{ML2R}
=
\frac{1}{d_{\text{features}}}
\sum_{j=1}^{d_{\text{features}}}
\frac{
\left\| \vec{U}_{:,\mathrm{mcs}(j)} \vec{V}_{\mathrm{mcs}(j),j} \right\|_2
}{
\left\| W_{:,j} \right\|_2
}
\end{equation}
where $\mathrm{mcs}(j)$ is the index of the most aligned subcomponent for feature $j$. A ratio near $1$ indicates the feature is fully captured by its best-aligned subcomponent.

\subsection{ Toy Model of Compressed Computation }
\label{sec:tcc-experiment}
The Toy Model of Compressed Computation,
a model that was already studied by SPD \autocite{stochasticparameterdecomposition}, APD \autocite{AttributionBasedParameterDecomposition} and more recently by \autocite{bhagat2025compressed}, is a
toy model trained to compute the elementwise function $y_i = x_i + \mathrm{ReLU}(x_i)$ through a residual MLP with a lower-dimensional hidden layer.

The architecture consists of an embedding matrix $W_E$, an unembedding matrix $W_U = W_E^\top$, and a residual MLP with input projection $W_{\text{in}} \in \mathbb{R}^{50 \times d_{\text{emb}}}$ and output projection $W_{\text{out}} \in \mathbb{R}^{d_{\text{emb}} \times 50}$.
The input vectors are sparse activations sampled from a uniform distribution over $[-1, 1]$, with the model trained to minimize the MSE between the output and the target function. The model's computation can be expressed as:
\[
    y = W_U \big( W_E x + W_{\text{out}}(\mathrm{ReLU}(W_{\text{in}} W_E x)) \big).
\]
For comparability with previous work, the experiments use $d_{\text{features}} = 100$, $d_{\text{MLP}} = 50$, rank $k=1$ matrices, $C = 200$ subcomponents and lastly an embedding dimension $d_{\text{emb}} = 1000$.

\begin{figure}[H]
    \centering
    \includegraphics[width=10cm, height=5cm]{CCmodel.png}
    \caption{Architecture of the Toy Model of Compressed Computation. Picture taken from \autocite{bhagat2025compressed}}
\end{figure}

A naive decomposition of this model would be to let
each of the neurons in the hidden layer compute one of the $100$ ReLU computations.
However this would would perform poorly, on the remaining $50$ neurons. Instead,
to achieve a better reconstruction, the model seems to learn a more efficient representation by assigning
multiple features to the same neuron.

The ground truth for $W_{\text{in}}$ is clear:
each subcomponent should be causally important for one input feature
matching the independent one-dimensional structure of the inputs.

For $W_{\text{out}}$, the ground truth is less clear.
APD \autocite{AttributionBasedParameterDecomposition} initially suspected a monosemantic decomposition where each subcomponent corresponds to one output feature,
to be the most truthful decomposition. SPD \autocite{stochasticparameterdecomposition} on the other hand
reports a polysemantic decomposition in which $50$ subcomponents
each contribute to multiple features while the remaining
are pruned to near-zero norm.


Another paper \autocite{bhagat2025compressed}
supports the interpretation of SPD, showing that 
the model does not implement $100$ separate computations
through superposition but rather that they jointly operate within a shared
$50$-dimensional subspace.

\subsubsection{Causal importance}
The experimentation with Softmax seems to replicate a similar structure to that 
found in APD \autocite{AttributionBasedParameterDecomposition},
where one subcomponent is causally important for one feature,
while the remaining subcomponents have negligible importance for that feature in both layers.

\begin{figure}[H]
    \centering
    \includegraphics[width=\linewidth, height=8cm]{softmax_CC.jpg}
    \caption{Causal importance values for Softmax on the Toy Model of Compressed Computation. Each input feature activates a near one-hot importance pattern across subcomponents. Sampled using one-hot sampling.}
    \label{fig:cc_importance}
\end{figure}

If this reading is taken at face value,
there should only be two possible interpretations, either
each subcomponent learns a monosemantic representation for one feature, and the remaining
subcomponents are unimportant and can be ablated. Alternatively,
the minimality loss is too strong and forces the model to concentrate all importance on a single subcomponent, at the cost of reconstruction
which should be reflected in a high reconstruction error.
Surprisingly, as seen in table \ref{tab:resid_mlp_sampling},
Softmax produces near-zero reconstruction error,
and should therefore have recovered a monosemantic decomposition.

To examine this, the neuron contributions for both the target model and softmax are plotted in figure \ref{fig:cc_contribution}.
The computation of the contribution is computed as in SPD \autocite{stochasticparameterdecomposition}.
\begin{align}
    \text{NeuronContribution}_{\text{model}}(i) &= \left( W_{U[i,:]}W_{out} \right) \odot \left( W_{in}W_{E}[:,i] \right) \\
    \text{NeuronContribution}_{\text{subcomponent}}(i) &= \max_{c \in C} \left[\left( W_{U[i,:]} U_{\text{out}} V_{\text{out}^{T}} \right) \odot \left(U_{\text{in}[:,c]}V^{T}_{in}[c,:] W_{E}[:,i] \right) \right] 
\end{align}
where $W_{E[:,i]}$ and $W_{U[i,:]}$ are the $i$-th column and row of the embedding and unembedding matrices
and $\odot$ denotes elementwise multiplicaiton.

$ W_{U[i,:]}W_{out} $ measures how strongly the neurons contribute to the "reconstruction" of the output,
while $ W_{in}W_{E}[:,i] $ measures how strongly the neurons are activated by the input feature $i$.
If both produce high values, the product will be high, indicating that the neuron contributes strongly to the feature's computation.
Otherwise if either is low, the contribution will be low, indicating that the neuron does not contribute significantly to that feature.

As seen in figure \ref{fig:cc_contribution},
Softmax, like SPD, find subcomponents that contribute to multiple features,
which also replicates the behaviour of the target model.
\begin{figure}[H]
    \centering
    \includegraphics[width=\linewidth, height=8cm]{component_contribution_soft_max.jpg}
    \caption{Per-feature contribution of each subcomponent at the neuron level. Subcomponents contribute to multiple features simultaneously, even when their causal importance is concentrated on a single feature.}
    \label{fig:cc_contribution}
\end{figure}

The one-hot importance assignment is therefore not equivalent to a monosemantic
parameter decomposition. One initial reading would be that the subcomponents
represent multiple features in superposition, with the observed interference
arising from near-orthogonal subcomponents. However,this is contradictory to the results found by \autocite{bhagat2025compressed}, which show that the trained $W_{\text{out}}$ operates within a shared $50$-dimensional subspace rather than implementing $100$ separate computations.

If softmax was genuinely encoding $100$ features in superposition,
the $U_c$ and $V_c$ vectors of its $100$ active subcomponents would have to be near-orthogonal.
To examine this, the pairwise cosine similarity between the $U_c$ and $V_c$
vectors of the causally important subcomponents are computed
in figure \ref{fig:CC_cosines}.

For $W_{\text{in}}$, both methods recover near-orthogonal $V$ vectors,
an expected result, as the embedding dimension is large enough

The $U$ vectors, by contrast, must project into the $50$-dimensional

Interestingly, the two methods find wildly different projections in the $U$ space.
Softmax finds two clusters, where the first $80$ subcomponents have large positive cosine similarities with each other and large negative similarities with the remaining $20$, while the final $20$ are positively correlated among themselves.
SPD on the other hand find many subcomponents sharing similar directions, but without the clear two-cluster structure observed in SPD.

For $W_{\text{out}}$, the two methods diverge in their representation. In SPD, the $50$ causally important subcomponents recover orthogonal directions in both $U$ and $V$, while the remaining subcomponents are entangled but carry negligible norm and contribute nothing to the final projection.

The softmax variant, which assigns causal importance to $100$ subcomponents,

The $U$ vectors on the otherhand, find the same two-cluster pattern as in $W_{\text{in}}$, with the first $80$ subcomponents having small positive cosine similarities with each other and large negative similarities with the remaining $20$,
while the final $20$ practically collapse onto the same direction.

As briefly mentioned in TMS, but also observed in the CC model,
softmax produces feature shrinkage, even when it produces the right feature directions.
To quantify if this could be the cause of insufficient norm concentration, the norms of the subcomponents are examined. (Figure \ref{fig:CC_norms})

The two methods recover very different norm distributions.
Consistent with the cosine similarity analysis, softmax
separates into two broad clusters: approximately the first 80 subcomponents have
substantially larger norms, while the remaining 120 retain smaller but non-negligible norms in both $W_{in}$ and $W_{out}$.

Notably, the softmax does not drive unused subcomponents to zero norm, but rather to a small but non-negligible value.

SPD, by contrast, concentrates norm almost exclusively in the causally important subcomponents: approximately 100 subcomponents for $W_{\text{in}}$ and 50 for $W_{\text{out}}$. The remaining subcomponents are effectively pruned, with norms close to zero rather than forming the residual low-norm tail observed in the softmax decomposition.

A further observation is that the norm contributions differ systematically between the two layers. In $W_{\text{in}}$, the norm is dominated primarily by the $V$ vectors, whereas in $W_{\text{out}}$ the dominant contribution instead comes from the $U$ vectors. This pattern is consistent across both decomposition methods.

An initial hypothesis for why the softmax formulation fails to produce hard-zero norms was that, unlike the hard-sigmoid gating used in SPD, the softmax distribution cannot produce exact zeros. However, the plot over the causal importance value frequencies rule out this explanation (Figure \ref{fig:CC_causal_importance_hist}).
The learned importance assignments are nearly bimodal, with most 
concentrated at either $0$ or $1$, and only a small fraction occupying
intermediate values. (Figure \ref{fig:CC_causal_importance_hist}) The absence of hard-zero norms therefore seems
not to arise from the gating distribution itself, but rather from how
reconstruction mass is distributed across subcomponents during optimisation.
Empirically, this hypothesis was further weakened by replacing the softmax gating with sparsemax \autocite{peters2019sparsesequencetosequencemodels}, which is capable of producing exact zeros in the gating distribution. Despite this, the resulting norm distributions remained qualitatively identical to those obtained with softmax.

More generally, this behaviour is likely related to the feature
shrinkage phenomenon previously observed in both TMS and CC.
The faithfulness objective is computed additively as the MSE between
the summed subcomponent reconstruction and the target weight matrix,
making it indifferent to how reconstruction mass is allocated
across subcomponents. Consequently, if the importance regularisation only weakly
penalises low-magnitude subcomponents, optimisation may converge
to solutions in which a small set of dominant subcomponents carry
most of the semantic structure, while a long tail of weakly active
components absorbs residual reconstruction error.

\subsection{Toy Model of Geometry}

In the paired TMS regime, even though input features were nominally two-dimensional, the model collapsed them onto a single direction, so a rank-1 decomposition per feature was sufficient. To test the rank-$k$ extension of Section~\ref{sec:rank-k-attention}, a setting is needed where features cannot collapse to a single direction.
This experiment generalizes the cube example from the introduction, where a model is trained to compute the volume of an $n$-dimensional simplex from its $n+1$ vertices in $\mathbb{R}^n$:
\begin{equation}
    \text{Vol}(v_1, \ldots, v_{n+1}) = \frac{1}{n!} \left| \det\!\left( \begin{bmatrix} v_2 - v_1 & v_3 - v_1 & \cdots & v_{n+1} - v_1 \end{bmatrix} \right) \right|.
\end{equation}


To mirror the paired-feature setup of Section~\ref{sec:tms-tied-experiment}, the model receives $K$ simplices as input, each sampled with probability $p$ and otherwise set to zero across all of its coordinates:
\begin{equation}
    f(x) = W_2 \text{ReLU}(W_1 x), \quad W_1 \in \mathbb{R}^{d_{\text{hidden}} \times K n(n+1)}, \quad W_2 \in \mathbb{R}^{K \times d_{\text{hidden}}},
\end{equation}
here $n(n+1)$ is the total number of coordinates of a simplex in $\mathbb{R}^n$ and $K$ is the number of simplices.
Concretely, for this experiment the simplices are triangles in $\mathbb{R}^2$, with $K = 3$ and $d_{\text{hidden}} = 150$.

Unlike TMS, $d_{\text{hidden}}$ is chosen to be much greater than the input dimension (here $d_{in}= 18$), so that the model does not need to compress features through superposition.
The intention being that the model assigns each simplex to a
separate subset of neurons, allowing the routing of information
from input to output to be studied in isolation, as the minimality
loss is applied at different strengths and as the rank
is increased.

The volume of a simplex is an irreducible feature in the
sense of Section~\ref{sec:irreducibility}, provided the model learns
the volume itself rather than a proxy that only approximates it.
The volume is computed from the $n+1$ vertices of the simplex, which
are affinely independent by construction: no vertex lies in the affine hull
of the others, so the volume depends on all of them jointly.

Any computation faithful to the volume must therefore represent the
vertices together, and no partition of them into separate parts can
determine the volume independently. The volume is thus neither separable,
since its representation cannot factor into independent components,
nor a mixture of a lower-dimensional feature, since the vertices
of an active simplex are always jointly present, with no partial feature
that activates on its own while the rest remains inactive. 
The volumes of different simplices, by contrast, are separable from one another,
since each depends on a disjoint set of vertices and can be computed independently.

The ground-truth decomposition for $W_{1}$ should therefore group each simplex
into a single unit and keep distinct simplices in distinct units. 
For $W_{2}$, meanwhile, the structure is less clear. The
volume is computed by the same function for every simplex, so whether the
model implements this through shared or separate neurons determines the
ground-truth decomposition. In this case the model appears to learn a separate
computation for each simplex, as shown in the next section.

Whether the decomposition method can recover this structure should
depend on two factors: the dimensionality each subcomponent is allowed
to represent, and how strongly the minimality loss penalises spreading
importance across multiple subcomponents.
As these parameters are varied, the recovered decomposition is expected
to change gradually:
A subcomponent may capture progressively
larger fractions of a single simplex, converging towards the ground-
truth decomposition. Alternatively, the additional capacity may be
used to represent parts of multiple simplices simultaneously,
resulting in a decomposition that mixes otherwise independent computations.

\subsubsection{Target model structure}
To examine, how the model learns to compute the volume,
a similar approach to that of Section \ref{sec:tcc-experiment} is adopted,
where the routing strength from each simplex to each output is measured by
decomposing the preactivations of the hidden neurons into contributions
from each simplex, and then measuring how strongly those neurons contribute
to the output.

Concretely, three quantities are defined over hidden neurons.
Firstly, how strongly each simplex influences a hidden neurons state,
secondly how strongly each hidden neuron contributes to the volume output of each simplex,
and lastly how strongly the path from layer l to layer l+1 routes information from simplex g to output k through neuron i.

Firstly, let
the input features be partitioned into $K$ disjoint groups,
where group $g$ contains the $n(n+1)$ coordinates of simplex $g$ denoted
by $\mathcal{C}_g$, with the groups jointly covering all input columns.

Let $W_l^{(g)}$ denote $W_l$ restricted to the columns in $\mathcal{C}_g$
and zero elsewhere, such  that $W_l = \sum_{g=1}^{K} W_l^{(g)}$ \footnote{Note we define both $W^g$ and $W^{c}$, technically they canco occur. Perhaps define a seperate notation? }.
The preactivation of hidden neuron $i$ then decomposes additively
over the groups:
\begin{equation}
    \sum_{c} W_{l[i,c]} = \sum_{g=1}^{K} \rho_{l,[i,g]}, \qquad \rho_{l,[i,g]} := \sum_{c} W^{(g)}_{l[i,c]},
\end{equation}
here $\rho_{l,[i,g]}$, measures the additive contribution of input group g to the preactivation of neuron i.”

On the output side, the strength with which hidden neuron
$i$ contributes to the volume computation of simplex $k$
is given directly by
\begin{equation}
    \pi_{l+1,[k,i]} := W_{l+1[k,i]}
\end{equation}

Finally, the strength of the path from simplex $g$ to output $k$ through neuron $i$ is given by the product of these two factors. 

Let $s_{i}$ denote the strongest of such paths for neuron $i$ across all simplices and outputs.
\begin{equation}

\subsubsection{Subcomponent structure}
Unlike the target model, where the hidden neurons
are the object of interest, the subcomponent analysis
steps one level back to measure how strongly individual subcomponents
route into one another.
This requires defining the same three quantities as before, but at the subcomponent level rather than the neuron level.

In particular, let $W^{(c)}_{l}$ be a subcomponent of layer $l$, defined in the same manner as in Section $\ref{sec:rank-k-attention}$,
such that $\sum_{c=1}^{C} W^{(c)}_{l} = W_l$.
Then analogously to before, define the additive contribution of simplex $g$ on the hidden neurons of subcomponent $c$ in layer
$W_{l}$ as
\begin{equation}
    \rho^{(c)}_{l,[i,g]}
    := \sum_{j \in \mathcal{C}_g}\left(W^{(c)}_{l,[i,j]}\right) \quad \text{such that } \rho_{l,[i,g]} = \sum_{c=1}^{C} \rho^{(c)}_{l,[i,g]}
\end{equation}
Secondly, the additive contribution of hidden neuron $i$ to output $k$ through subcomponent $c$ is given by
\begin{equation}
    \pi^{(c)}_{l+1,[k,i]} := \left(W^{(c)}_{l+1[k,i]}\right) \quad \text{such that } \pi_{l+1,[k,i]} = \sum_{c=1}^{C} \pi^{(c)}_{l+1,[k,i]}
\end{equation}

Lastly, define the subcomponent routing matrix $\Psi \in \mathbb{R}^{|C|\times|C|}$
as the matrix product between the total influence of all input features on the hidden neurons
and the total contribution of the hidden neuron to all output features.

\begin{equation}
    \Psi_{c',c} := \sum_{i=1}^{d_{\text{hidden}}} \left( \sum_{k=1}^{d_{\text{out}}} W^{(c')}_{l+1,[k,i]} \right) \left( \sum_{j=1}^{d_{\text{in}}} W^{(c)}_{l,[i,j]} \right).
\end{equation}
Like before, a larger value indicates a stronger routing from subcomponent $c$ to subcomponent $c'$.
These three quantities together describe the routing through the decomposition. The input contribution
$\rho^{(c)}_{l,[i,g]}$ shows how each simplex group feeds into subcomponent $c$, the output contribution $\pi^{(c)}_{l+1,[k,i]}$ shows how subcomponent $c$ feeds into each output, and the routing matrix $\Psi_{c',c}$ composes the two, measuring how strongly a subcomponent that reads from the input ($c$) connects to one that writes to the output ($c'$) through shared hidden neurons.

\subsection{The non-uniqueness of the minimal decomposition}
% Your strongest, most original point. Build it carefully.
\begin{itemize}
    \item Rank-1 with one component per feature is not, in general, the minimal description: in the paired regime, an aligned pair can be captured by one rank-1 subcomponent or split across two, both reconstructing identically.
    \item The rank constraint therefore does not determine a unique decomposition; it admits a coarser grouping and a finer splitting of the same aligned directions.
    \item Minimality in the number of components is a property of how the importance function groups or splits, not of the rank constraint alone.
    \item This is the ambiguity the relational importance function is designed to resolve: pressuring jointly-manipulated directions toward a shared subcomponent.
    \item Connect to the underdetermination of the objective: reconstruction plus $\ell_p$ minimality plus rank-1 does not pin down a canonical factorisation.
\end{itemize}

\subsection{The non-uniqueness of the minimal decomposition}

A rank-1 decomposition with one component per feature is often taken to be the minimal description of a computation, but the paired regime shows that it is not. When a feature pair is aligned onto a single direction, it can be captured by one rank-1 subcomponent or split across two, and both reconstruct the target identically. The rank constraint therefore does not pick out a unique decomposition: it admits both a coarser grouping and a finer splitting of the same aligned directions, with no difference in faithfulness to separate them. Minimality in the number of components is thus not determined by the rank constraint alone, but by how the importance function chooses to group or split. This is the ambiguity the relational importance function is designed to resolve, pressuring directions that are manipulated jointly toward a shared subcomponent rather than leaving the grouping to chance. More broadly, it shows that reconstruction, $\ell_p$ minimality, and a rank-1 constraint together do not pin down a canonical factorisation; the decomposition that emerges is selected as much by the inductive bias of the importance function as by any intrinsic property of the model.

\subsection{Limitations and future work}
\begin{itemize}
    \item The softmax variant does not produce hard zeros; sparsemax and entmax do not resolve the residual magnitude, which may grow with the number of subcomponents.
    \item The relational importance function scales quadratically in the number of subcomponents, unlike SPD's linear independent importance functions.
    \item SPD recovers clean structure on the geometric model only within a narrow minimality range, raising a robustness question.
    \item Future directions: adversarial ablation combined with relational importance; attention approximations to reduce the quadratic cost; direct evaluation of the mixture condition.
    \item This paper does not address mixtures, and therefore does not conclude on every aspect of irreducibility.
    \item Toy models.
\end{itemize}
