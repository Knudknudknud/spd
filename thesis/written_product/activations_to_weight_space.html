From activations to weight space

Interpreting rank-$k$ parameter decomposition as input-dependent SVD, and what it reveals about individual mechanisms

1. The decomposition as SVD

Sparse autoencoders and related methods decompose neural networks in activation space — they ask "what directions are present in this activation vector?" Our decomposition operates in weight space — it asks "what functions does this weight matrix implement, and which ones are active for this input?"

The structural parallel to SVD makes this precise. A standard SVD of a weight matrix $W$ is:

$$W = U \Sigma V^\top$$

Geometrically, the SVD says that every linear transformation $W$ can be decomposed into three operations applied in sequence:

$\vec{x} \in \mathbb{R}^{d_\mathrm{in}}$
input
→
$V^\top \vec{x}$
rotate into aligned basis
→
$\Sigma (V^\top \vec{x})$
scale each axis
→
$U (\Sigma V^\top \vec{x})$
rotate into output space

Step 1: $V^\top$ — rotation into the aligned basis. The columns of $V$ form an orthonormal basis for $\mathbb{R}^{d_\mathrm{in}}$. Multiplying by $V^\top$ rotates the input vector from the standard basis into this new basis. In the new coordinate system, the axes are aligned with the "natural directions" of the matrix — the directions along which it acts most simply. No stretching or distortion happens here; it is a pure rotation (an isometry).

Step 2: $\Sigma$ — scaling in the aligned space. Once in the aligned basis, the matrix's action is diagonal: each axis is independently scaled by its singular value $\sigma_i$. A large $\sigma_i$ means the matrix amplifies signal along that direction; a small $\sigma_i$ means it suppresses it; $\sigma_i = 0$ means that direction is annihilated entirely. This is the core of what the matrix "does" — its effect, stripped of all rotational structure, is just a set of per-axis scalings.

Step 3: $U$ — rotation into the output space. The scaled vector now lives in the aligned basis of the output space. Multiplying by $U$ rotates it into the standard basis of $\mathbb{R}^{d_\mathrm{out}}$. The columns of $U$ are the orthonormal directions in the output space that the matrix writes to — each singular value's contribution is delivered along its corresponding column of $U$.

The full picture is: rotate to find the natural axes, scale along each axis, rotate into the output. Every matrix, no matter how complex, reduces to this: a choice of input directions, a choice of output directions, and a set of scalings connecting them.

Our decomposition has the same three-stage structure:

$$W'(x) = \sum_{c=1}^{C} U_c \, \mathrm{diag}(\mathbf{m}_c(x)) \, V_c^\top$$

Each subcomponent reproduces the same three stages: $V_c^\top$ rotates the input into the subcomponent's aligned basis, $\mathrm{diag}(\mathbf{m}_c(x))$ scales each axis in that basis, and $U_c$ rotates the result into the output space. The geometry is identical to classical SVD, with two differences.

First, the scaling is input-dependent. In a standard SVD, the singular values $\sigma_i$ are fixed — they are properties of the matrix. Here, the masks $[m_c(x)]_j$ change per input. The importance function decides, for each input, how much signal each axis should carry. A singular value of $[m_c]_j \approx 0$ means that axis is effectively annihilated for this input, just as $\sigma_i = 0$ annihilates a direction in classical SVD — but here it may be restored for a different input.

Second, the decomposition has multiple blocks. A classical SVD decomposes one matrix into one set of directions. Our decomposition decomposes one matrix into $C$ separate sets of directions, each with its own rotation-scale-rotation pipeline. Different subcomponents read from different subspaces of the input ($V_c$), scale independently ($\mathrm{diag}(\mathbf{m}_c)$), and write to different subspaces of the output ($U_c$). The weight matrix is not one rotation-scale-rotation — it is a superposition of $C$ of them, selectively activated per input.

What this shift in perspective buys us

In activation space, we observe the result of a computation — the activation vector after the weight matrix has been applied. In weight space, we observe the computation itself — the reading and writing subspaces that the matrix uses, and which of them are active. This is the difference between observing a program's output and observing which subroutines were called.

2. The projection pipeline

For a single subcomponent $c$, the action on an input activation $\vec{a}(x)$ proceeds in three stages:

$\vec{a}(x) \in \mathbb{R}^{d_\mathrm{in}}$
activation
→
$V_c^\top \vec{a}(x) \in \mathbb{R}^k$
project
→
$\mathrm{diag}(\mathbf{m}_c) \cdot V_c^\top \vec{a}(x)$
gate
→
$U_c(\ldots) \in \mathbb{R}^{d_\mathrm{out}}$
lift

Project. The matrix $V_c^\top$ projects the high-dimensional activation onto a $k$-dimensional subspace. This is the mechanism's reading operation — it extracts the $k$ dimensions of the input that are relevant to this particular computation, discarding everything else.

Gate. The mask $\mathrm{diag}(\mathbf{m}_c(x))$ scales each of the $k$ projected dimensions independently. Dimensions with $[m_c]_j \approx 1$ pass through; dimensions with $[m_c]_j \approx 0$ are suppressed. This is the bottleneck — the effective rank of the mechanism for this input.

Lift. The matrix $U_c$ embeds the gated result back into the high-dimensional output space, along the mechanism's writing directions.

The inner activation $\mathbf{h}_c(x) = V_c^\top \vec{a}(x) \in \mathbb{R}^k$ is the mechanism's view of the input — the input as seen through the lens of this particular computation. Different mechanisms see different projections of the same activation. The importance function then determines, from this projected view, whether the mechanism should be active.

3. Understanding individual components

The decomposition makes each mechanism independently inspectable. For a given subcomponent $c$, we can examine:

What it reads. The columns of $V_c \in \mathbb{R}^{d_\mathrm{in} \times k}$ span a $k$-dimensional subspace of the input activation space. By examining which input features have large projections onto this subspace, we can determine what information the mechanism uses.

What it writes. The columns of $U_c \in \mathbb{R}^{d_\mathrm{out} \times k}$ span a $k$-dimensional subspace of the output activation space. This determines where the mechanism sends its result — which downstream computations it feeds into.

When it activates. The importance values $g_c(x)$ over the training distribution reveal on which inputs the mechanism is causally important. The set $\{x : g_c(x) > \tau\}$ defines the mechanism's receptive field in data space.

Its effective rank. Under per-dimension ablation, the mean importance per dimension $\mathbb{E}_x[|[m_c(x)]_j|]$ reveals how many of the $k$ available dimensions the mechanism actually uses. A mechanism that consistently uses only $r < k$ dimensions has learned an effective rank of $r$, with the remaining $k - r$ dimensions pruned by the minimality loss.

Each subcomponent is a self-contained description of a mechanism: where it reads from, where it writes to, when it is active, and how much capacity it uses. This is a complete functional characterisation that is not available from activation-space methods, which observe the superposition of all mechanisms simultaneously.

4. Does the model learn to group features?

The central empirical question is whether the decomposition recovers meaningful mechanisms — whether related features are grouped into the same subcomponent, and unrelated features are separated.

Consider a target model that represents "day of the week" as a 2-dimensional circular feature (requiring rank 2) and "is uppercase" as a 1-dimensional linear feature (requiring rank 1). With $k = 4$, a successful decomposition would produce:

Subcomponent $c_1$: day of the week

Mean per-dimension importance: $(0.97, \; 0.95, \; 0.02, \; 0.01)$

Two active dimensions, two suppressed. Effective rank: 2.

The columns of $V_{c_1}$ span the 2D plane containing the circular representation. The inner activation $\mathbf{h}_{c_1}(x) \in \mathbb{R}^4$ has its first two entries tracing a circle as the day varies, and its last two entries near zero.

Subcomponent $c_2$: is uppercase

Mean per-dimension importance: $(0.94, \; 0.03, \; 0.01, \; 0.01)$

One active dimension, three suppressed. Effective rank: 1.

The columns of $V_{c_2}$ align with the single direction encoding case information.

The effective rank is learned, not prescribed. Both subcomponents had $k = 4$ dimensions available, but the minimality loss pruned the unused ones. The decomposition has implicitly discovered that "day of the week" requires rank 2 and "is uppercase" requires rank 1.

If the decomposition fails to group features correctly — if, for example, the $\cos$ and $\sin$ components of the circular representation end up in different subcomponents — this would manifest as two subcomponents that always co-activate. Their importance values $g_{c_1}(x)$ and $g_{c_2}(x)$ would be highly correlated across the training distribution, which is detectable and diagnostic.

5. Measuring subspace overlap

When two subcomponents share subspace — when their reading or writing directions are not orthogonal — they interfere with each other. The degree of overlap is measurable directly from the learned parameters.

Define the interference between mechanisms $c$ and $c'$ as:

$$\mathrm{I}(c, c') = \|U_c^\top U_{c'}\|_F^2 + \|V_c^\top V_{c'}\|_F^2$$

This is zero when the mechanisms occupy orthogonal subspaces and large when they share directions. Arranging these values into a $C \times C$ matrix gives a global view of how the model's mechanisms relate to each other.

But the sum $\mathrm{I}(c, c')$ conflates two distinct relationships. Because the decomposition is a read-scale-write pipeline, the two terms have separate interpretations:

$$\mathrm{I}_\mathrm{read}(c, c') = \|V_c^\top V_{c'}\|_F^2$$

measures how much two mechanisms read from the same input directions. If this is large, both mechanisms extract information from the same part of the input activation. They react to the same signals — they are sensitive to the same features of the input.

$$\mathrm{I}_\mathrm{write}(c, c') = \|U_c^\top U_{c'}\|_F^2$$

measures how much two mechanisms write to the same output directions. If this is large, both mechanisms contribute to the same downstream computations. Their outputs add up in the same subspace — they influence the same factors in the next layer.

These can be reported separately, and the four combinations tell different stories:

Four cases

Low read, low write. The mechanisms are fully independent — different inputs, different outputs. They can be understood in complete isolation.

High read, low write. Both mechanisms respond to the same input features, but route their outputs to different places. They are parallel processors of the same signal, contributing to different downstream computations.

Low read, high write. The mechanisms respond to different inputs, but contribute to the same output directions. They are converging pathways — different sources of information that feed into the same downstream computation.

High read, high write. The mechanisms share both input and output subspace. They are either redundant (doing the same thing) or in genuine superposition (the model has packed more computations into this subspace than it has dimensions for).

The decomposition therefore reveals not only what each mechanism does (its reading and writing subspaces), when it is active (its importance values), and how much capacity it uses (its effective rank), but also how it relates to every other mechanism — and whether that relationship is on the input side, the output side, or both.

6. Visualising the interference matrix

Consider a toy model decomposed into $C = 5$ subcomponents. The interference matrix might look like this:

$c_1$$c_2$$c_3$$c_4$$c_5$
$c_1$—0.020.010.710.03
$c_2$0.02—0.340.050.01
$c_3$0.010.34—0.020.04
$c_4$0.710.050.02—0.01
$c_5$0.030.010.040.01—

Reading the matrix

$c_1$ and $c_4$ have high interference ($0.71$). They share substantial subspace — they are in superposition. Ablating one will affect the other. These two mechanisms are entangled and should be analysed jointly rather than in isolation.

$c_2$ and $c_3$ have moderate interference ($0.34$). They share some subspace but are largely separable. Each can be approximately understood on its own, but with the caveat that interactions exist.

$c_5$ has low interference with everything. It occupies its own subspace and can be studied in complete isolation. This is the cleanest kind of mechanism — fully disentangled from the rest of the model.

This matrix can be computed directly from the learned $U_c$ and $V_c$ matrices, with no additional training or inference. It provides an immediate, quantitative answer to the question: which mechanisms in this model can be understood independently, and which are entangled?

Encouraging the decomposition toward orthonormality — via a regularisation loss on the cross-component terms:

$$\mathcal{L}_\mathrm{ortho} = \lambda_\mathrm{cross} \sum_{c \neq c'} \mathrm{I}(c, c')$$

pushes the off-diagonal entries toward zero. The residual — the interference that remains after regularisation — measures the degree to which the model genuinely requires superposition. It cannot be eliminated by the decomposition method; it is a property of the target model itself.

The interference matrix is both a diagnostic and a measure of interpretability. Low off-diagonal values mean the decomposition has found mechanisms that can be understood in isolation. High values mean the model's computations are fundamentally entangled — not a failure of the method, but a property of the model made visible.

7. Orthogonality as an implicit clustering force

The cross-component regularisation $\mathcal{L}_\mathrm{ortho}$ does more than encourage interpretability — it provides the structural force that pushes dependent features into the same subcomponent.

Consider two dependent features — say $\cos(\theta)$ and $\sin(\theta)$ of a circular representation — that together span a 2-dimensional subspace $\mathcal{S}$ in the target model. Suppose the decomposition places them in separate subcomponents $c$ and $c'$. Then $U_c$ and $U_{c'}$ must both point into $\mathcal{S}$, because that is where the target model stores these features. But this means:

$$\|U_c^\top U_{c'}\|_F^2 \gg 0$$

The cross-component loss detects this overlap and penalises it. The gradient pushes the decomposition to resolve the overlap. There are only two ways to do so:

Option A: consolidate

Move both features into a single subcomponent. The overlap becomes internal — $U_c$ spans the full 2D subspace on its own — and the cross-component penalty vanishes. This is the desired outcome.

Option B: separate into orthogonal subspaces

Rotate $U_c$ and $U_{c'}$ to be orthogonal. But this is impossible if the features are genuinely dependent — the target model stores them in the same subspace, and any rotation that makes the subcomponents orthogonal would break faithfulness. The decomposition cannot reconstruct $W$ faithfully if the subcomponents point away from where the features actually live.

So the faithfulness loss prevents Option B, and the cross-component loss penalises the current state. The only remaining path is Option A: consolidation. Dependent features are pushed into the same subcomponent because separating them creates cross-component overlap that cannot be resolved without violating faithfulness.

The orthogonality regulariser serves as an implicit clustering mechanism. It does not require knowing which features are dependent — the overlap structure reveals this automatically. Features that share subspace in the target model will share subspace in the decomposition, and the cross-component penalty ensures this sharing happens within a subcomponent rather than across subcomponents.

8. The interference matrix as a clustering diagnostic

Before the orthogonality regulariser is applied, the interference matrix reveals which subcomponents the decomposition has failed to properly separate — and therefore which features are candidates for consolidation. After training with the regulariser, the residual interference reveals whether consolidation succeeded.

Consider a decomposition trained without $\mathcal{L}_\mathrm{ortho}$. The interference matrix might show:

$c_1$$c_2$$c_3$$c_4$$c_5$
$c_1$—0.820.030.010.02
$c_2$0.82—0.040.020.01
$c_3$0.030.04—0.010.03
$c_4$0.010.020.01—0.02
$c_5$0.020.010.030.02—

The high interference between $c_1$ and $c_2$ ($0.82$) signals that these two subcomponents occupy nearly the same subspace. They are likely fragments of a single multi-dimensional feature that was split across two subcomponents. All other pairs have low interference — they are already well-separated.

After retraining with $\mathcal{L}_\mathrm{ortho}$, the regulariser drives $c_1$ and $c_2$ to consolidate. The resulting decomposition has one fewer subcomponent, and the interference matrix becomes:

$c_{1}'$$c_3$$c_4$$c_5$
$c_{1}'$—0.050.020.01
$c_3$0.05—0.010.03
$c_4$0.020.01—0.02
$c_5$0.010.030.02—

The merged subcomponent $c_1'$ now captures the full multi-dimensional feature as a single rank-2 block. The interference matrix is uniformly low — all mechanisms occupy approximately orthogonal subspaces.

Reading the before/after as a clustering story

The interference matrix before regularisation is a similarity matrix over subcomponents. High entries indicate subcomponents that share subspace and should be merged. The matrix is, in effect, an adjacency matrix for a clustering problem: connected components in the thresholded interference graph correspond to groups of features that belong together.

The interference matrix after regularisation shows the result of that clustering. If all off-diagonal entries are low, the decomposition has successfully grouped all dependent features. If some remain high, those features are in genuine superposition in the target model — they share subspace not because the decomposition failed, but because the model requires it.

The orthogonality regulariser transforms the decomposition from a method that must be told how to group features into one that discovers the grouping itself. The interference matrix makes this grouping visible, both as a pre-training diagnostic (which features should be grouped?) and as a post-training validation (were they?).
