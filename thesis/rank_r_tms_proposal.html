Rank-r Toy Model of Superposition

A dataset where GNN-based importance functions provably outperform SPD's independent gates.

1. Background: standard TMS (rank-1 features)

In Elhage et al.'s Toy Model of Superposition, we have n scalar features squeezed through an m-dimensional bottleneck (m < n). The model learns to reconstruct sparse inputs:

x̂ = ReLU(W⊤W x + b),    W ∈ ℝm × n

Each column wi of W is a single direction in ℝm — a rank-1 mechanism. SPD finds these perfectly because each mechanism is already rank-1, matching SPD's subcomponent structure exactly.

Figure 1: Standard TMS. Each feature is a scalar, each mechanism is a single direction (rank 1).

2. Generalisation: rank-r features

Replace each scalar feature with an r-dimensional vector. Now we have n features, each in ℝr. Total input dimension is d = n · r. The bottleneck dimension m satisfies m < n · r, forcing superposition.

x̂ = σ(W⊤W x + b),    W ∈ ℝm × (n·r)

The columns of W are grouped into n blocks of r:

W = [ W₁ | W₂ | ··· | Wₙ ],    each Wᵢ ∈ ℝm × r

Each block Wi is a rank-r mechanism. When feature i is active, all r columns of Wi are jointly needed to encode and decode the r-dimensional input.

Figure 2: Rank-r TMS. Each feature is r-dimensional, each mechanism spans r columns of W.

3. Data distribution

Input x ∈ ℝn·r is generated blockwise. For each feature i ∈ {1, …, n}, independently:

x(i) ~ Unif(Sr−1)   with probability s,    x(i) = 0   with probability 1 − s

where s ≪ 1 is the sparsity parameter and Sr−1 is the unit (r−1)-sphere. Sampling from the sphere ensures all r dimensions carry information — none can be discarded.

Numeric example

Parameters: n = 3 features, r = 2, sparsity s = 0.3. Since r = 2, the unit sphere Sr−1 = S1 is just the unit circle. Sampling from it means picking a random angle θ and computing (cos θ, sin θ).

Figure 3: Concrete numeric example of generating a rank-2 input vector.
Why is this irreducibly rank-2?

The value (0.50, 0.87) encodes the angle θ = 60° on the unit circle. If you only kept 0.50, you couldn't distinguish θ = 60° from θ = 300° (which also has cos = 0.50 but sin = −0.87). Both coordinates are needed together. For higher r, the same logic applies on Sr−1.

4. Training objective

Standard autoencoding with importance weighting:

ℒ = Σᵢ λᵢ ‖x̂⁽ⁱ⁾ − x⁽ⁱ⁾‖²

where λi are importance weights and x̂(i) is the reconstruction of the i-th r-dimensional block.

5. Ground truth mechanisms

The correct decomposition has exactly n parameter components, one per feature. Component i is the rank-r matrix:

Mᵢ = Wᵢ Wᵢ⊤ ∈ ℝm × m    (rank r)

Component i should be active (importance ≈ 1) when x(i) ≠ 0 and inactive (importance ≈ 0) otherwise.

6. Why SPD's independent gates fail

SPD decomposes W into rank-1 subcomponents. For feature i, it finds r subcomponents {ci,1, …, ci,r} corresponding to the r columns of Wi. Each gets an independent gate:

gci,j(x) = σH( γci,j( hci,j(x) ) )

where hci,j(x) = vi,j⊤ a(x) is a single scalar.

Figure 4: The two failure modes of SPD's independent importance functions.

Problem 1: interference

The scalar hci,j(x) contains interference from other features because in superposition the vectors v are not orthogonal. Gate γci,1 sees one number and must decide: "is this signal from my feature, or interference from others?" It can't check with its partner ci,2 — if both dimensions of feature i are receiving correlated signal, that's strong evidence feature i is truly active. But an independent gate can't perform that cross-check.

Problem 2: co-activation

Even if each gate is individually accurate, you need all r gates for one feature to agree. That probability drops as pr.

7. Why a GNN fixes this

A GNN replaces the independent γci,j(hci,j) with a function that can see neighbouring subcomponents via message passing:

h̃ci,j(x) = AGG( hci,j(x), { hci,j'(x) }j' ≠ j )

Three capabilities of the GNN

1. Vote on activation: if r−1 of the r dimensions show signal, the r-th can infer it should also be active, even if its own scalar is ambiguous.

2. Reject interference: if only 1 of r dimensions shows signal (likely interference), all r gates agree to stay inactive.

3. Enforce consistency: the importance values are functions of the shared representation, so gci,1 ≈ gci,2 ≈ ··· ≈ gci,r by construction.

8. Experimental design

Fix n (number of features), m (hidden dimension), and s (sparsity). Train target models for r ∈ {1, 2, 4, 8, 16}. Decompose each with both vanilla SPD and GNN-SPD.

Prediction

At r = 1, both methods perform equally (no multi-dimensional structure to exploit).

As r grows, SPD's accuracy drops because its independent gates increasingly disagree on co-activation.

The GNN maintains performance because message passing enforces consistency across the r subcomponents of each feature.
